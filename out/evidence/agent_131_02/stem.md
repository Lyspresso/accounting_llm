### Q3 — CORE alternate angle — Internal-use software and cloud hosting service contract
**LO:** LO 13-8  
**Concept:** Internal-use software (preliminary vs application development; training expensed); cloud computing hosting as service contract — capitalize implementation, expense subscription, amortize over hosting term; period-end adjusting JEs; classification/presentation of cloud implementation costs  
**Scenario:**  
**HarborPoint Retail Group** (calendar-year) has two software initiatives in **2025**.

**Part A — Internal-use software**  
HarborPoint developed cash-management software **solely for internal use** (not sold or marketed). Cash costs:
1. Preliminary project stage (needs assessment, vendor evaluation, technology selection): **$18,000**
2. Application development stage (coding, configuration, testing, installation to ready-for-use): **$240,000** employee and contractor costs
3. Training employees on the new system (incurred during and after development): **$12,000**
4. Software was **substantially complete and ready for intended use on July 1, 2025**. Estimated useful life: **4 years**, residual value zero, amortize **straight-line**. HarborPoint records full-month amortization starting in July.

**Part B — Cloud computing arrangement**  
On **January 1, 2025**, HarborPoint entered a **four-year** cloud hosting arrangement for an ERP module. HarborPoint **does not** have a contractual right to take possession of the software without significant penalty (and cannot practically run it on its own hardware). Arrangement cash terms:
1. Implementation / setup costs paid January 1, 2025: **$80,000** (development-stage implementation costs)
2. Annual subscription (hosting) fee paid each **December 31**: **$96,000**
3. Implementation is complete and ready for intended use on January 1, 2025; amortize capitalized implementation costs **straight-line over the 4-year hosting term**.

**Required:**  
a. **Internal-use:** Compute the amount **initially capitalized**. Prepare JEs for (i) preliminary costs, (ii) application development costs, and (iii) training costs.  
b. **Internal-use:** Prepare the **2025 period-end amortization JE** and state December 31, 2025 **carrying amount**. Show a brief **amortization schedule** for 2025–2028 (full years after 2025).  
c. **Cloud:** Is the arrangement a **service contract** or a **software purchase**? Explain using the possession criteria.  
d. **Cloud:** Prepare the **January 1, 2025** JE for implementation costs, the **December 31, 2025** JE for the subscription fee, and the **December 31, 2025** amortization adjusting JE.  
e. Prepare a **cloud subsequent measurement schedule** for the implementation asset over the four-year term (beginning BV, amortization, ending BV each year).  
f. **Classification / presentation:** How should HarborPoint present (i) the capitalized cloud implementation costs on the **balance sheet**, (ii) amortization of those costs on the **income statement**, and (iii) related cash flows on the **statement of cash flows**?
