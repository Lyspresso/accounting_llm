This project verifies 1,828 AI-generated accounting study questions.
Every question must end as `verified` (with evidence) or `needs_human`
(with a dossier). Nothing is trusted without evidence — including the
tools doing the checking.

## Step 3 — hard rules (violating any of these is an error)

1. Never edit anything in deliverables/ by hand. It is generated by
   deliver.sh.
2. Never edit or delete anything in skill/releases/. Releases are
   append-only.
3. Never commit textbook source files (Hanlon 4e chapter text) — this
   repo is public. The .gitignore blocks common names; do not work
   around it.
4. Never quote a number as current without checking docs/03-03-RETIRED.md.
5. Never re-open a settled ruling without citing its ID from
   docs/02-02-DECISIONS.md and presenting new evidence.
6. Only two terminal states exist: `verified` and `needs_human`.
   `machine_passed` is progress, not completion.
7. The LAUNCH GATE is RED right now. Nothing runs the remaining corpus
   until the pre-flight turns it GREEN. (Tranche 1 then fires
   automatically — that authorization is already recorded.)
8. Every spec change ships immediately as the next patch release
   (next: v1.4.4). Update docs in the same commit as the work.
