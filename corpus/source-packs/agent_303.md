# Agent 303 — CORE DEMO — LO 8-3

**Chapter:** 8  
**LO title:** Account for the impact of sales returns and allowances  
**Critical gap LO:** no  
**Emphasis angle:** period_end_adjusting_JE

## Concept list for this pack
- Sales returns and allowances as **variable consideration** that reduce the **transaction price** / **Net Sales** (ASC 606)
- **Sales Returns** (contra revenue) vs **Sales Allowances** (contra revenue; customer keeps goods—**no** inventory restore)
- **Initial recognition:** credit sales + perpetual COGS; actual returns (sales-side + cost-side); actual allowances (sales-side only)
- **Period-end adjusting JE (emphasis):** Dr **Sales Returns** / Cr **Refund Liability** for remaining expected returns; Dr **Inventory—Estimated Returns** / Cr **COGS** for cost of remaining estimate
- First-year identity: ending Refund Liability = total estimated returns − actual returns already recorded
- **Subsequent measurement / rollforward:** subsequent year charges actual returns to Sales Returns, then true-ups Refund Liability so ending balance = estimated remaining returns on **current-year** sales
- **Settlement JE:** when a return is identified with amounts already accrued, debit Refund Liability (not Sales Returns) and reclassify Inventory—Estimated Returns to Inventory
- Classification: Net Sales on the income statement; Refund Liability (current liability); Inventory—Estimated Returns (current asset)

**Method note (core exam path — Demo 8-3 / Review 8-3):** In practice, record **actual** returns and allowances during the period, then at **period-end** accrue the **remaining** expected returns. Both the “estimate every sale” and “actual + YE estimate” approaches yield the same period-end statements. Material estimate vs. actual differences are **changes in accounting estimate**.

### Q1 — CORE — Harborwick Sporting Goods: first-year sales, returns, allowances, YE estimate

**LO:** LO 8-3  
**Concept:** initial_recognition_JE — actual returns & allowances; **period_end_adjusting_JE** for Refund Liability and Inventory—Estimated Returns (emphasis)  
**Scenario:**  
**Harborwick Sporting Goods Co.** begins operations in Year 1 and sells athletic equipment **on account**. Harborwick uses a **perpetual** inventory system. Customers may return merchandise for a **cash refund**. Cost of merchandise is consistently **64%** of selling price. During Year 1:

| Item | Amount |
|------|--------:|
| Credit sales | **$720,000** |
| Cost of goods sold on those sales (64%) | **$460,800** |
| Actual cash refunds for merchandise returns | **$18,000** |
| Sales allowances granted (customers keep goods; credit to AR) | **$2,880** |

At December 31, Year 1, Harborwick estimates **total** sales returns for the year at **3%** of credit sales (based on industry experience and expected economic conditions). No Refund Liability or Inventory—Estimated Returns balances existed at the start of Year 1.

**Required:**  
(a) Record the Year 1 entries for **credit sales** and related **cost of goods sold**.  
(b) Record the entries for **actual sales returns** during the year (sales-side and cost-side).  
(c) Record the entry for **sales allowances**.  
(d) Compute total estimated returns and the **remaining** estimate at year-end. Record the December 31 **period-end adjusting entries** for estimated returns (sales-side and cost-side) — **emphasis**.  
(e) Prepare a **Refund Liability rollforward** (beginning → YE plug → ending). Compute **Net Sales** for Year 1 and state year-end balance-sheet classification of Refund Liability and Inventory—Estimated Returns.  
(f) Briefly contrast the accounting for a **sales return** with a **sales allowance**.

**Answer key:**

**(a) Credit sales and COGS — Year 1**

| Account | Debit | Credit |
|---|---:|---:|
| Accounts Receivable | 720,000 | |
| Sales Revenue | | 720,000 |
| *Record Year 1 credit sales* | | |

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 460,800 | |
| Inventory | | 460,800 |
| *Perpetual COGS; 720,000 × 0.64* | | |

**Check:** Dr 720,000 = Cr 720,000; Dr 460,800 = Cr 460,800. Cost check: \(720{,}000 \times 0.64 = 460{,}800\). **Balanced.**

**(b) Actual sales returns during Year 1**

Sales-side (cash refunds):

| Account | Debit | Credit |
|---|---:|---:|
| Sales Returns | 18,000 | |
| Cash | | 18,000 |
| *Actual returns — reduce net sales; cash refund* | | |

Cost-side (restore inventory; reverse COGS):  
\(18{,}000 \times 0.64 = \mathbf{\$11{,}520}\)

| Account | Debit | Credit |
|---|---:|---:|
| Inventory | 11,520 | |
| Cost of Goods Sold | | 11,520 |
| *Restore cost of returned merchandise* | | |

**Check:** Dr = Cr on each entry. **Balanced.**

**(c) Sales allowances (customer keeps goods — no inventory entry)**

| Account | Debit | Credit |
|---|---:|---:|
| Sales Allowances | 2,880 | |
| Accounts Receivable | | 2,880 |
| *Price concession; goods retained — sales-side only* | | |

**Check:** Dr 2,880 = Cr 2,880. **No** Inventory or COGS entry for an allowance. **Balanced.**

**(d) Period-end estimated returns — December 31, Year 1 (emphasis)**

Total estimated returns = \(0.03 \times 720{,}000 = \mathbf{\$21{,}600}\).  
Remaining estimate (Refund Liability) = \(21{,}600 - 18{,}000 = \mathbf{\$3{,}600}\).

| Account | Debit | Credit |
|---|---:|---:|
| Sales Returns | 3,600 | |
| Refund Liability | | 3,600 |
| *YE adjusting JE: remaining expected returns on Year 1 sales* | | |

Cost of remaining estimated returns = \(3{,}600 \times 0.64 = \mathbf{\$2{,}304}\)  
(equivalently: total cost of estimated returns \(21{,}600 \times 0.64 = 13{,}824\) minus inventory already restored \(11{,}520\)).

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Estimated Returns | 2,304 | |
| Cost of Goods Sold | | 2,304 |
| *YE adjusting JE: right to recover products expected to be returned* | | |

**Check:** Dr = Cr on each entry. Combined Year 1 Sales Returns = \(18{,}000 + 3{,}600 = 21{,}600\) (= total estimate). **Balanced.**

**(e) Schedule, Net Sales, presentation**

**Refund Liability rollforward — Year 1**

| Component | Amount |
|---|---:|
| Beginning Refund Liability | $0 |
| + Additional estimate (YE plug) | 3,600 |
| − Actual returns applied to liability during year* | 0 |
| **Ending Refund Liability** | **$3,600** |

\*Under the common practice used in Demo 8-3 / first-year start-up, actual returns are charged to **Sales Returns** (not Refund Liability); the YE plug sets the liability equal to remaining estimated returns.

Cross-check identity: ending liability = total estimated returns − actual returns recorded = \(21{,}600 - 18{,}000 = 3{,}600\).

**Net Sales — Year 1**

| | Amount |
|---|---:|
| Sales Revenue | $720,000 |
| − Sales Returns (\(18{,}000 + 3{,}600\)) | (21,600) |
| − Sales Allowances | (2,880) |
| **Net Sales** | **$695,520** |

**Balance sheet (December 31, Year 1) — classification**  
- **Refund Liability $3,600** — current liability (expected refunds of consideration the entity does not expect to be entitled to).  
- **Inventory—Estimated Returns $2,304** — current asset (right to recover products expected to be returned).

**(f) Return vs allowance**  
A **sales return** brings merchandise back: reduce net sales **and** restore Inventory / reduce COGS. A **sales allowance** is a price concession so the customer **keeps** the goods: only a contra-revenue entry (Sales Allowances); inventory and COGS are unchanged.

**Key insight:** Companies record **actual** returns (and allowances) as they occur, then at **period-end** accrue the **remaining** expected returns with Refund Liability and Inventory—Estimated Returns so Net Sales reflects the transaction price the entity expects to be entitled to (ASC 606 variable consideration). The period-end adjusting pair is the exam-critical step.

### Q2 — CORE number variant — Northpine Kitchenware: first-year twin

**LO:** LO 8-3  
**Concept:** initial_recognition_JE and **period_end_adjusting_JE** (number-variant twin of Q1)  
**Scenario:**  
**Northpine Kitchenware Inc.** is in its first year of operations. It sells on account, uses perpetual inventory, and grants **cash** refunds on returns. Merchandise cost is **55%** of selling price. Year 1 data:

| Item | Amount |
|------|--------:|
| Credit sales | **$960,000** |
| Cost of goods sold (55%) | **$528,000** |
| Actual cash refunds for returns | **$24,000** |
| Sales allowances (credit to AR; goods retained) | **$4,800** |
| Estimated **total** returns at year-end | **4%** of credit sales |

No beginning Refund Liability or Inventory—Estimated Returns.

**Required:**  
(a) Record sales and COGS.  
(b) Record actual returns (sales-side and cost-side).  
(c) Record sales allowances.  
(d) Record December 31 **period-end adjusting entries** for estimated returns (both sides) — **emphasis**.  
(e) Compute Net Sales and ending balances of Refund Liability and Inventory—Estimated Returns. Show the identity: ending Refund Liability = total estimated returns − actual returns.

**Answer key:**

**(a) Sales and COGS**

| Account | Debit | Credit |
|---|---:|---:|
| Accounts Receivable | 960,000 | |
| Sales Revenue | | 960,000 |

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 528,000 | |
| Inventory | | 528,000 |

**Check:** \(960{,}000 \times 0.55 = 528{,}000\). Dr = Cr. **Balanced.**

**(b) Actual returns**

| Account | Debit | Credit |
|---|---:|---:|
| Sales Returns | 24,000 | |
| Cash | | 24,000 |

Inventory restored: \(24{,}000 \times 0.55 = \mathbf{\$13{,}200}\)

| Account | Debit | Credit |
|---|---:|---:|
| Inventory | 13,200 | |
| Cost of Goods Sold | | 13,200 |

**Check:** Dr = Cr. **Balanced.**

**(c) Sales allowances**

| Account | Debit | Credit |
|---|---:|---:|
| Sales Allowances | 4,800 | |
| Accounts Receivable | | 4,800 |

**Check:** Dr = Cr. No inventory entry. **Balanced.**

**(d) December 31 estimated returns (period-end adjusting JE — emphasis)**

Total estimated returns = \(0.04 \times 960{,}000 = \mathbf{\$38{,}400}\).  
Remaining = \(38{,}400 - 24{,}000 = \mathbf{\$14{,}400}\).

| Account | Debit | Credit |
|---|---:|---:|
| Sales Returns | 14,400 | |
| Refund Liability | | 14,400 |
| *YE plug: remaining expected returns* | | |

Cost side: \(14{,}400 \times 0.55 = \mathbf{\$7{,}920}\)  
(equivalently: \(38{,}400 \times 0.55 = 21{,}120\) total estimated cost − \(13{,}200\) already restored).

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Estimated Returns | 7,920 | |
| Cost of Goods Sold | | 7,920 |
| *YE cost of remaining estimated returns* | | |

**Check:** Dr = Cr. Total Sales Returns = \(24{,}000 + 14{,}400 = 38{,}400\). **Balanced.**

**(e) Net Sales and ending balances**

| | Amount |
|---|---:|
| Sales Revenue | $960,000 |
| − Sales Returns | (38,400) |
| − Sales Allowances | (4,800) |
| **Net Sales** | **$916,800** |

| Account | Ending balance |
|---|---:|
| Refund Liability | **$14,400** |
| Inventory—Estimated Returns | **$7,920** |

Identity: ending Refund Liability = total estimated returns − actual returns = \(38{,}400 - 24{,}000 = 14{,}400\).  
Inventory—Estimated Returns = ending Refund Liability × cost % = \(14{,}400 \times 0.55 = 7{,}920\).

**Key insight:** Changing only the sales base, cost %, return rate, and actual returns still yields the same core structure: the **period-end adjusting JE** accrues the **unreturned** portion of the estimate so the liability and estimated-returns inventory equal remaining expected refunds and recoveries.

### Q3 — CORE alternate angle — Silverbrook Home Appliances: subsequent-year true-up, schedule, settlement

**LO:** LO 8-3  
**Concept:** subsequent_measurement_schedule; **period_end_adjusting_JE** (emphasis); disposal_maturity_or_settlement_JE; classification/presentation  
**Scenario:**  
**Silverbrook Home Appliances LLC** grants a 45-day return privilege. Cost of merchandise is **60%** of selling price. Silverbrook records **all actual returns during the year as if they arise from the current year** (debit Sales Returns), then adjusts Refund Liability at year-end so the **ending** balance equals estimated returns on **current-year** sales still expected next period. (This is the subsequent-period approach in Review 8-3.)

**January 1, Year 2 balances:**

| Account | Balance |
|---|---:|
| Refund Liability | **$11,500** |
| Inventory—Estimated Returns | **$6,900** |

**Year 2 activity:**

| Item | Amount |
|------|--------:|
| Credit sales | **$550,000** |
| COGS (60%) | **$330,000** |
| Actual returns (cash refunds), recorded as current-year Sales Returns | **$19,800** |
| Sales allowances on account | **$1,650** |
| Year-end estimate of returns related to Year 2 sales | **4.5%** of Year 2 credit sales |

Assume actual return rates are reasonably consistent with management’s estimates on average.

**Required:**  
(a) Record Year 2 sales and COGS.  
(b) Record actual returns (both sides) and sales allowances.  
(c) Compute the **target ending Refund Liability** and the year-end **period-end adjusting entries** for estimated returns (sales-side and cost-side) — **emphasis**.  
(d) Prepare a full **Refund Liability rollforward schedule** from beginning to ending balance. Also roll forward Inventory—Estimated Returns and confirm ending Inv—Est Returns = ending Refund Liability × 60%.  
(e) **Settlement alternate:** Suppose instead that on **January 18, Year 2**, Silverbrook identifies **$7,200** of cash returns (cost **$4,320**) as returns of Year 1 sales that had already been accrued in Refund Liability / Inventory—Estimated Returns. Record the **settlement** entries that reduce the liability and the estimated-returns asset (do **not** debit Sales Returns for this portion).  
(f) Report Net Sales for Year 2 under the main (Review 8-3) method in parts (a)–(d), and state balance-sheet presentation of the two estimated-return accounts.

**Answer key:**

**(a) Year 2 sales and COGS**

| Account | Debit | Credit |
|---|---:|---:|
| Accounts Receivable | 550,000 | |
| Sales Revenue | | 550,000 |

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 330,000 | |
| Inventory | | 330,000 |

**Check:** \(550{,}000 \times 0.60 = 330{,}000\). **Balanced.**

**(b) Actual returns and allowances (main method — charge Sales Returns)**

Sales-side returns:

| Account | Debit | Credit |
|---|---:|---:|
| Sales Returns | 19,800 | |
| Cash | | 19,800 |

Cost-side: \(19{,}800 \times 0.60 = \mathbf{\$11{,}880}\)

| Account | Debit | Credit |
|---|---:|---:|
| Inventory | 11,880 | |
| Cost of Goods Sold | | 11,880 |

Allowances:

| Account | Debit | Credit |
|---|---:|---:|
| Sales Allowances | 1,650 | |
| Accounts Receivable | | 1,650 |

**Check:** All entries balance. Refund Liability is **not** reduced when actual returns are recorded under this method; the YE true-up handles it. **Balanced.**

**(c) Period-end adjusting entries — December 31, Year 2 (emphasis)**

Estimated returns on Year 2 sales = \(0.045 \times 550{,}000 = \mathbf{\$24{,}750}\).

Target ending Refund Liability (Review 8-3 identity):  
\[
\begin{align*}
\text{Ending RL} &= \text{Beg RL} - \text{Actual returns} + \text{Est. on current-year sales} \\
&= 11{,}500 - 19{,}800 + 24{,}750 = \mathbf{\$16{,}450}
\end{align*}
\]

Adjusting plug to Refund Liability = \(16{,}450 - 11{,}500 = \mathbf{+\$4{,}950}\)  
(equivalently: \(24{,}750 - 19{,}800 = 4{,}950\)).

| Account | Debit | Credit |
|---|---:|---:|
| Sales Returns | 4,950 | |
| Refund Liability | | 4,950 |
| *YE true-up: set RL to remaining expected returns on Y2 sales* | | |

Cost-side plug: \(4{,}950 \times 0.60 = \mathbf{\$2{,}970}\)

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Estimated Returns | 2,970 | |
| Cost of Goods Sold | | 2,970 |
| *YE true-up of estimated-returns inventory* | | |

**Check:** Dr = Cr. Total Year 2 Sales Returns (main method) = \(19{,}800 + 4{,}950 = 24{,}750\) (= estimate on current-year sales).  
If the plug had been negative (actual returns > estimate on current sales), debit Refund Liability and credit Sales Returns (as can occur in Review 8-3). **Balanced.**

**(d) Subsequent measurement schedules**

**Refund Liability rollforward — Year 2**

| Date / component | Debit (decrease) | Credit (increase) | Balance |
|---|---:|---:|---:|
| Jan 1, Year 2 beginning | | | 11,500 |
| Actual returns (not charged to RL under main method) | — | — | 11,500 |
| Dec 31 YE true-up (est. on Y2 sales − actual) | | 4,950 | **16,450** |
| **Memo reconciling identity** | Actual 19,800 | Est. on Y2 sales 24,750 | Beg 11,500 − 19,800 + 24,750 = **16,450** |

**Inventory—Estimated Returns rollforward — Year 2**

| Component | Amount |
|---|---:|
| Beginning Inventory—Estimated Returns | $6,900 |
| + YE cost-side true-up | 2,970 |
| **Ending Inventory—Estimated Returns** | **$9,870** |

Confirm: ending Refund Liability × cost % = \(16{,}450 \times 0.60 = \mathbf{\$9{,}870}\). ✓

**(e) Settlement of prior-period estimate (alternate recording of returns of Year 1 sales)**

When a return is explicitly identified with amounts already accrued:

| Account | Debit | Credit |
|---|---:|---:|
| Refund Liability | 7,200 | |
| Cash | | 7,200 |
| *Settle accrued refund obligation for prior-year sales* | | |

| Account | Debit | Credit |
|---|---:|---:|
| Inventory | 4,320 | |
| Inventory—Estimated Returns | | 4,320 |
| *Reclassify estimated-returns asset to physical inventory recovered* | | |

**Check:** Dr = Cr on each entry. **Sales Returns is not debited** for this settlement—doing so would double-count the reduction already recognized when the estimate was accrued. After settlement, Refund Liability would be \(11{,}500 - 7{,}200 = 4{,}300\) before any further Year 2 true-up; Inventory—Estimated Returns would be \(6{,}900 - 4{,}320 = 2{,}580\). **Balanced.**

**(f) Net Sales (main method) and presentation**

| | Amount |
|---|---:|
| Sales Revenue | $550,000 |
| − Sales Returns (\(19{,}800 + 4{,}950\)) | (24,750) |
| − Sales Allowances | (1,650) |
| **Net Sales** | **$523,600** |

**Classification / presentation**  
- **Refund Liability $16,450** — current liability (refund obligation for consideration the entity does not expect to be entitled to).  
- **Inventory—Estimated Returns $9,870** — current asset (inventory expected to be recovered).

**Key insight:** In a subsequent year, the **period-end true-up** does not merely “add remaining returns”—it forces the Refund Liability ending balance to equal **estimated returns still outstanding on current-year sales** (beg − actual charged to current period + estimate on current sales). Settlement of prior accruals debits the **liability**, not Sales Returns.

### Q4 — MC — Classification of period-end estimated returns

**LO:** LO 8-3  
**Concept:** classification — Refund Liability vs. inventory asset vs. contra-receivable (method choice)  
**Question:**  
At year-end, a merchandiser estimates that customers will return **$8,000** of current-year credit sales for cash refunds; related inventory cost is **$4,800**. No portion of the estimate has yet been recorded. Under the **core Demo 8-3 approach**, which pair of accounts is correctly credited and debited (respectively) for the **sales-side** and **cost-side** period-end adjusting entries?

- A) Credit **Allowance for Sales Returns** (contra AR) $8,000; debit **Inventory** $4,800  
- B) Credit **Refund Liability** $8,000; debit **Inventory—Estimated Returns** $4,800  
- C) Credit **Sales Revenue** $8,000; debit **Cost of Goods Sold** $4,800  
- D) Credit **Accounts Payable** $8,000; debit **Prepaid Inventory Returns** $4,800  

**Answer:** **B.** Under Demo 8-3 / ASC 606, the sales-side YE entry is Dr Sales Returns / Cr **Refund Liability** for the remaining expected refunds; the cost-side entry is Dr **Inventory—Estimated Returns** / Cr COGS for the cost of goods expected to be recovered. Some academics mention a contra-AR **Allowance for Sales Returns** only if the return is associated with outstanding receivables, but the **core textbook path** uses **Refund Liability**. Option A is not the primary core presentation. Option C incorrectly reduces Sales Revenue directly and debits COGS (direction wrong for the cost recovery). Option D invents nonstandard accounts.
