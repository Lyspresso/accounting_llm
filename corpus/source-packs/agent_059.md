# Agent 59 — CORE DEMO — LO 10-3

**Chapter:** 10  
**LO title:** Demonstrate the relative sales value method to allocate costs to inventory  
**Critical gap LO:** no

## Concept list for this pack
- **Lump-sum (basket) purchase:** two or more inventory types acquired for one total price (plus allocable processing such as grading)
- **Relative sales value method:** allocate total cost to each inventory type based on each type’s share of total expected sales value
- **Allocation schedule:** quantity × unit selling price → total sales value → fraction of total sales value → allocated cost
- **Initial recognition JE:** debit separate inventory accounts by allocated cost; credit Cash (or Accounts Payable) for total lump-sum cost
- **Unit cost after allocation:** allocated cost ÷ quantity for each type (basis for COGS and ending inventory)
- **Constant gross profit percentage:** when cost is allocated on relative sales value, every type has the **same** GP% (sales − allocated cost) / sales
- **Subsequent measurement:** ending inventory = remaining units × allocated unit cost (perpetual inventory)
- **Disposal (sale):** cash/AR and sales at retail; COGS removes allocated cost of units sold
- **Land/lot basket purchases:** public/common areas are not separate inventory; full tract cost is allocated only to **salable** lots by relative sales value
- **Presentation:** inventory at allocated cost as a current asset (by category if material); COGS when sold

### Q1 — CORE — Graded produce basket purchase: allocation, initial JE, sales/COGS, ending inventory
**LO:** LO 10-3  
**Concept:** Relative sales value allocation of a lump-sum produce purchase; initial recognition JE; partial sale disposal; ending inventory schedule  
**Scenario:**  
Harbor Grove Orchards purchases **1,100 bushels** of ungraded walnuts for **$5,700 cash** on **September 5**. Same-day grading and sorting cost **$300 cash**. Total cost to allocate = **$6,000**. Grading produces three salable grades sold at different retail prices:

| Grade | Quantity (bushels) | Unit sales price |
|---|---:|---:|
| Grade A | 200 | $15 |
| Grade B | 400 | $10 |
| Grade C | 500 | $10 |

Harbor Grove uses a **perpetual** inventory system and the **relative sales value method**.

On **September 20**, Harbor Grove sells for cash: **120** Grade A, **250** Grade B, and **300** Grade C at the listed unit sales prices.

**Required:**  
a. Prepare the relative sales value **allocation schedule** (sales value, fraction, allocated cost, unit cost per grade).  
b. Record the **September 5** journal entry for the lump-sum purchase (including grading), allocated to separate inventory accounts.  
c. Compute **gross profit** and **gross profit percentage** for each grade assuming **all** units were sold at the listed prices (theoretical full-run proof).  
d. Record the **September 20** sale and cost of goods sold entries (by grade or combined with supporting amounts).  
e. Prepare the **ending inventory** valuation schedule by grade immediately after the September 20 sales.

**Answer key:**  

**a. Allocation schedule**  

| Grade | Qty | Unit SP | Total sales value | Fraction of total SV | Allocated cost | Unit cost |
|---|---:|---:|---:|---:|---:|---:|
| A | 200 | $15 | $3,000 | 3,000 / 12,000 = 0.25 | 0.25 × $6,000 = **$1,500** | $1,500 / 200 = **$7.50** |
| B | 400 | $10 | $4,000 | 4,000 / 12,000 = 1/3 | (1/3) × $6,000 = **$2,000** | $2,000 / 400 = **$5.00** |
| C | 500 | $10 | $5,000 | 5,000 / 12,000 = 5/12 | (5/12) × $6,000 = **$2,500** | $2,500 / 500 = **$5.00** |
| **Total** | **1,100** | | **$12,000** | **1.00** | **$6,000** | |

**Check:** Allocated costs $1,500 + $2,000 + $2,500 = **$6,000**.

**b. September 5 — initial recognition (lump-sum purchase allocated)**  

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Grade A Walnuts (200 bu.) | 1,500 | |
| Inventory—Grade B Walnuts (400 bu.) | 2,000 | |
| Inventory—Grade C Walnuts (500 bu.) | 2,500 | |
| Cash | | 6,000 |
| *To record basket purchase + grading; cost allocated by relative sales value* | | |

**Check:** Dr 1,500 + 2,000 + 2,500 = Cr 6,000. Balanced.

**c. Gross profit proof (if all units sold)**  

| Grade | Sales value | Allocated cost | Gross profit | GP% |
|---|---:|---:|---:|---:|
| A | $3,000 | $1,500 | $1,500 | 50% |
| B | 4,000 | 2,000 | 2,000 | 50% |
| C | 5,000 | 2,500 | 2,500 | 50% |
| **Total** | **$12,000** | **$6,000** | **$6,000** | **50%** |

**Key property:** Relative sales value allocation forces **identical GP%** across grades.

**d. September 20 — disposal (sale) and COGS**  

Sales revenue:  
- A: 120 × $15 = $1,800  
- B: 250 × $10 = $2,500  
- C: 300 × $10 = $3,000  
- **Total cash / sales = $7,300**

COGS (using allocated unit costs):  
- A: 120 × $7.50 = $900  
- B: 250 × $5.00 = $1,250  
- C: 300 × $5.00 = $1,500  
- **Total COGS = $3,650**

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 7,300 | |
| Sales Revenue | | 7,300 |
| *Cash sales of graded walnuts at retail* | | |

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 3,650 | |
| Inventory—Grade A Walnuts | | 900 |
| Inventory—Grade B Walnuts | | 1,250 |
| Inventory—Grade C Walnuts | | 1,500 |
| *Remove allocated cost of units sold* | | |

**Check:** Sale JE 7,300 = 7,300; COGS JE 3,650 = 900 + 1,250 + 1,500. Both balance.  
**Gross profit on actual sales:** $7,300 − $3,650 = **$3,650** (50% of sales).

**e. Ending inventory schedule (after Sept 20)**  

| Grade | Units remaining | Unit cost | Ending inventory |
|---|---:|---:|---:|
| A | 200 − 120 = 80 | $7.50 | **$600** |
| B | 400 − 250 = 150 | $5.00 | **$750** |
| C | 500 − 300 = 200 | $5.00 | **$1,000** |
| **Total** | | | **$2,350** |

**Rollforward check:** Beginning allocated inventory $6,000 − COGS $3,650 = ending inventory **$2,350**.

**Key insight:** The relative sales value method assigns the basket cost in proportion to each grade’s revenue-producing ability. Higher-priced grades absorb more of the lump-sum cost, but GP% is the same for every grade. After allocation, perpetual inventory tracking and COGS use those allocated unit costs—not a uniform average cost across grades.

### Q2 — CORE number variant — Almond grades: recompute allocation, purchase JE, partial sale, EI
**LO:** LO 10-3  
**Concept:** Number-variant twin of relative sales value allocation, initial recognition, disposal, and ending inventory  
**Scenario:**  
Summit Ridge Packers purchases **2,400 bags** of ungraded almonds for **$14,400 cash** on **October 1**. Sorting cost is **$1,600 cash**. Total cost to allocate = **$16,000**.

| Grade | Quantity (bags) | Unit sales price |
|---|---:|---:|
| Premium | 400 | $20 |
| Select | 800 | $15 |
| Standard | 1,200 | $10 |

On **October 18**, Summit Ridge sells for cash: **300** Premium, **500** Select, and **800** Standard at the listed prices. Perpetual inventory; relative sales value method.

**Required:**  
a. Allocation schedule (sales value, fraction, allocated cost, unit cost).  
b. October 1 purchase journal entry.  
c. October 18 sale and COGS journal entries.  
d. Ending inventory by grade after October 18.  
e. Prove total GP% on the October 18 sales equals the theoretical full-run GP%.

**Answer key:**  

**a. Allocation schedule**  

| Grade | Qty | Unit SP | Total SV | Fraction | Allocated cost | Unit cost |
|---|---:|---:|---:|---:|---:|---:|
| Premium | 400 | $20 | $8,000 | 8,000 / 32,000 = 0.25 | **$4,000** | **$10.00** |
| Select | 800 | $15 | $12,000 | 12,000 / 32,000 = 0.375 | **$6,000** | **$7.50** |
| Standard | 1,200 | $10 | $12,000 | 12,000 / 32,000 = 0.375 | **$6,000** | **$5.00** |
| **Total** | **2,400** | | **$32,000** | **1.00** | **$16,000** | |

**Check:** $4,000 + $6,000 + $6,000 = $16,000.  
**Theoretical full-run GP%:** ($32,000 − $16,000) / $32,000 = **50%**.

**b. October 1 — initial recognition**  

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Premium Almonds | 4,000 | |
| Inventory—Select Almonds | 6,000 | |
| Inventory—Standard Almonds | 6,000 | |
| Cash | | 16,000 |

**Check:** Dr 16,000 = Cr 16,000.

**c. October 18 — sale and COGS**  

Sales: 300 × $20 + 500 × $15 + 800 × $10 = $6,000 + $7,500 + $8,000 = **$21,500**  
COGS: 300 × $10 + 500 × $7.50 + 800 × $5 = $3,000 + $3,750 + $4,000 = **$10,750**

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 21,500 | |
| Sales Revenue | | 21,500 |

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 10,750 | |
| Inventory—Premium Almonds | | 3,000 |
| Inventory—Select Almonds | | 3,750 |
| Inventory—Standard Almonds | | 4,000 |

**Check:** 21,500 = 21,500; 10,750 = 3,000 + 3,750 + 4,000.

**d. Ending inventory**  

| Grade | Units left | Unit cost | EI |
|---|---:|---:|---:|
| Premium | 100 | $10.00 | $1,000 |
| Select | 300 | $7.50 | $2,250 |
| Standard | 400 | $5.00 | $2,000 |
| **Total** | | | **$5,250** |

**Rollforward:** $16,000 − $10,750 = **$5,250**.

**e. GP% proof on actual sales**  
GP = $21,500 − $10,750 = **$10,750**  
GP% = $10,750 / $21,500 = **50%** (matches full-run GP%).

**Key insight:** Changing quantities, prices, and total cost does not change the method: form sales-value fractions, multiply by total lump-sum cost, then use resulting unit costs for all later COGS and inventory measurements.

### Q3 — CORE alternate angle — Land subdivision lots: purchase allocation, sales disposal, period-end inventory, presentation
**LO:** LO 10-3  
**Concept:** Relative sales value for real-estate lot inventory; sales/COGS disposal; period-end carrying amounts; BS classification/presentation  
**Scenario:**  
Northridge Development Co. purchases a tract of land for **$500,000 cash** on **March 1**. The tract is subdivided as follows:

- Common walkways, drainage, and open space (not sold as inventory lots; cost is absorbed in lot allocation).  
- **10 Vista lots** expected to sell for **$50,000** each.  
- **20 Ridge lots** expected to sell for **$25,000** each.  
- **20 Valley lots** expected to sell for **$12,500** each.

Northridge uses a perpetual inventory system and the relative sales value method. Treat each lot category as a separate inventory account.

During the year Northridge sells for cash: **6 Vista lots**, **12 Ridge lots**, and **15 Valley lots** at the listed prices. No lots are impaired; net realizable value exceeds allocated cost for all remaining lots at year-end.

**Required:**  
a. Prepare the relative sales value allocation schedule and the **March 1** purchase journal entry.  
b. Prepare journal entries for the **year’s cash sales and COGS** for each lot category (may combine sales; show COGS by category).  
c. Prepare the **period-end inventory valuation schedule** by category (subsequent measurement of remaining inventory). Is a period-end **write-down adjusting entry** required under the facts given?  
d. **Classification / presentation:** How should remaining lot inventory be reported on the year-end classified balance sheet? What amount?

**Answer key:**  

**a. Allocation and March 1 purchase JE**  

| Category | Lots | Unit SP | Total SV | Fraction | Allocated cost | Cost per lot |
|---|---:|---:|---:|---:|---:|---:|
| Vista | 10 | $50,000 | $500,000 | 500,000 / 1,250,000 = 0.40 | **$200,000** | **$20,000** |
| Ridge | 20 | $25,000 | $500,000 | 500,000 / 1,250,000 = 0.40 | **$200,000** | **$10,000** |
| Valley | 20 | $12,500 | $250,000 | 250,000 / 1,250,000 = 0.20 | **$100,000** | **$5,000** |
| **Total** | **50** | | **$1,250,000** | **1.00** | **$500,000** | |

Public/common areas receive **no separate inventory balance**; their cost is included in the $500,000 and allocated entirely to salable lots via relative sales value.

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Vista Lots (10) | 200,000 | |
| Inventory—Ridge Lots (20) | 200,000 | |
| Inventory—Valley Lots (20) | 100,000 | |
| Cash | | 500,000 |
| *Lump-sum land purchase allocated to salable lots by relative sales value* | | |

**Check:** Dr 200,000 + 200,000 + 100,000 = Cr 500,000. Balanced.

**b. Disposal — sales and COGS**  

Sales:  
- Vista: 6 × $50,000 = $300,000  
- Ridge: 12 × $25,000 = $300,000  
- Valley: 15 × $12,500 = $187,500  
- **Total sales = $787,500**

COGS:  
- Vista: 6 × $20,000 = $120,000  
- Ridge: 12 × $10,000 = $120,000  
- Valley: 15 × $5,000 = $75,000  
- **Total COGS = $315,000**

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 787,500 | |
| Sales Revenue | | 787,500 |
| *Cash sales of lots at listed prices* | | |

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 315,000 | |
| Inventory—Vista Lots | | 120,000 |
| Inventory—Ridge Lots | | 120,000 |
| Inventory—Valley Lots | | 75,000 |
| *Remove allocated cost of lots sold* | | |

**Check:** 787,500 = 787,500; 315,000 = 120,000 + 120,000 + 75,000.  
**GP:** $787,500 − $315,000 = **$472,500**; GP% = 472,500 / 787,500 = **60%**  
(= ($1,250,000 − $500,000) / $1,250,000).

**c. Period-end inventory schedule (subsequent measurement)**  

| Category | Lots remaining | Cost per lot | Carrying amount |
|---|---:|---:|---:|
| Vista | 10 − 6 = 4 | $20,000 | **$80,000** |
| Ridge | 20 − 12 = 8 | $10,000 | **$80,000** |
| Valley | 20 − 15 = 5 | $5,000 | **$25,000** |
| **Total ending inventory** | | | **$185,000** |

**Rollforward:** $500,000 − $315,000 = **$185,000**.

**Period-end adjusting entry:** **None required** under the given facts. Inventory remains at allocated **cost**. NRV exceeds cost for remaining lots, so no lower-of-cost-or-NRV write-down is indicated. (Relative sales value sets **initial cost**; LCNRV is a separate subsequent measurement rule from LO 10-1, not applied here.)

**d. Classification / presentation**  
- Report **Inventory** (or Inventory—Real estate lots held for sale) as a **current asset** at the aggregate carrying amount **$185,000**, unless management’s operating cycle supports noncurrent classification for lots expected to sell beyond one year (exam default for lot inventory held for sale in the normal course: **current**).  
- Disclosure (optional detail): Vista $80,000; Ridge $80,000; Valley $25,000.  
- Common areas are **not** a separate inventory line; their cost is already embedded in lot carrying amounts via the relative sales value allocation.  
- Income statement: Sales **$787,500**, COGS **$315,000**, gross profit **$472,500**.

**Key insight:** For land subdivided into lots, allocate the **entire** tract cost to salable lots using relative sales values—do not capitalize a separate “public space” inventory. Sales remove allocated lot cost through COGS. At period-end, remaining lots stay at allocated cost absent an impairment / LCNRV trigger.

### Q4 — MC (method / allocated amount)
**LO:** LO 10-3  
**Concept:** Identify relative sales value allocation and compute allocated cost for one inventory group  

**Question 1:**  
A company acquires several grades of inventory in a single lump-sum (basket) purchase. Under U.S. GAAP textbook treatment illustrated for LO 10-3, the preferred basis for assigning the lump-sum cost to each grade is:

- A) Equal cost per unit to every grade regardless of selling price  
- B) Relative **sales value** (revenue-producing ability) of each grade  
- C) Relative physical weight or volume only  
- D) Net realizable value after a mandatory year-end write-down to zero for lower grades  

**Answer:** **B.** The relative sales value method allocates lump-sum cost in proportion to each type’s total expected sales value so cost follows economic utility. Equal unit cost (A) ignores different benefits; weight/volume (C) is not the LO 10-3 method; LCNRV write-downs (D) are a separate subsequent measurement issue, not the allocation basis at purchase.

---

**Question 2:**  
Canyonview Properties purchases land for **$1,200,000** cash and subdivides it into salable lots (common areas have no separate sales value; full cost is allocated to lots):

| Group | Number of lots | Price per lot |
|---|---:|---:|
| Group A | 15 | $40,000 |
| Group B | 25 | $48,000 |
| Group C | 20 | $30,000 |

Using the relative sales value method, the **allocated cost of Group B** land inventory is:

- A) $576,000  
- B) $600,000  
- C) $480,000  
- D) $1,200,000  

**Answer:** **B. $600,000.**  
Sales values: A = 15 × $40,000 = $600,000; B = 25 × $48,000 = $1,200,000; C = 20 × $30,000 = $600,000; **total SV = $2,400,000**.  
Group B fraction = $1,200,000 / $2,400,000 = 0.50.  
Allocated cost = 0.50 × $1,200,000 = **$600,000**.  

Distractors: A is Group B’s sales value × wrong fraction or 25 × $ something; C is Group A/C cost share ($600k SV / $2,400k × $1,200k = $300k each would be correct for A/C—not listed); D is total purchase price with no allocation.
