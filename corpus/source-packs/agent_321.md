# Agent 321 — CORE DEMO — LO 10-3

**Chapter:** 10  
**LO title:** Demonstrate the relative sales value method to allocate costs to inventory  
**Critical gap LO:** no  
**Emphasis angle:** period_end_adjusting_JE

## Concept list for this pack
- **Lump-sum (basket) purchase:** two or more inventory types acquired for one total price (plus allocable grading/sorting)
- **Relative sales value method:** allocate total cost to each inventory type based on each type’s share of total expected sales value
- **Allocation schedule:** quantity × unit selling price → total sales value → fraction of total sales value → allocated cost → unit cost
- **Initial recognition JE:** debit separate inventory accounts for allocated cost; credit Cash (or AP) for total lump-sum cost
- **Constant gross profit percentage:** when cost is allocated on relative sales value, every type has the **same** GP%
- **Disposal (sale):** record sales at retail; remove allocated cost via COGS
- **Subsequent measurement schedule:** ending inventory = remaining units × allocated unit cost
- **Period-end adjusting JE:** when sales revenue was recorded during the period but COGS/inventory relief was not, record the year-end (or period-end) adjusting entry to recognize COGS and reduce inventory; remaining lots stay at allocated cost absent LCNRV impairment
- **Land/lot basket purchases:** public/common areas receive no separate inventory; full tract cost is allocated only to **salable** lots by relative sales value

### Q1 — CORE — Graded produce basket: allocation, initial JE, disposal, ending inventory
**LO:** LO 10-3  
**Concept:** Relative sales value allocation of a lump-sum produce purchase; initial recognition JE; partial sale disposal; ending inventory schedule  
**Scenario:**  
Cedar Peak Packing purchases **1,000 bushels** of ungraded plums for **$3,400 cash** on **September 8**. Same-day sorting and grading cost **$200 cash**. Total cost to allocate = **$3,600**. Sorting yields three salable grades sold at different retail prices:

| Grade | Quantity (bushels) | Unit sales price |
|---|---:|---:|
| Grade A | 100 | $18.00 |
| Grade B | 300 | $9.00 |
| Grade C | 600 | $4.50 |

Cedar Peak uses a **perpetual** inventory system and the **relative sales value method**.

On **September 22**, Cedar Peak sells for cash: **70** Grade A, **180** Grade B, and **400** Grade C at the listed unit sales prices.

**Required:**  
a. Prepare the relative sales value **allocation schedule** (sales value, fraction, allocated cost, unit cost per grade).  
b. Record the **September 8** journal entry for the lump-sum purchase (including sorting), allocated to separate inventory accounts.  
c. Compute **gross profit** and **gross profit percentage** for each grade assuming **all** units were sold at the listed prices (theoretical full-run proof).  
d. Record the **September 22** sale and cost of goods sold entries.  
e. Prepare the **ending inventory** valuation schedule by grade immediately after the September 22 sales.

**Answer key:**  

**a. Allocation schedule**  

| Grade | Qty | Unit SP | Total sales value | Fraction of total SV | Allocated cost | Unit cost |
|---|---:|---:|---:|---:|---:|---:|
| A | 100 | $18.00 | $1,800 | 1,800 / 7,200 = 0.25 | 0.25 × $3,600 = **$900** | $900 / 100 = **$9.00** |
| B | 300 | $9.00 | $2,700 | 2,700 / 7,200 = 0.375 | 0.375 × $3,600 = **$1,350** | $1,350 / 300 = **$4.50** |
| C | 600 | $4.50 | $2,700 | 2,700 / 7,200 = 0.375 | 0.375 × $3,600 = **$1,350** | $1,350 / 600 = **$2.25** |
| **Total** | **1,000** | | **$7,200** | **1.00** | **$3,600** | |

**Check:** Allocated costs $900 + $1,350 + $1,350 = **$3,600**.

**b. September 8 — initial recognition (lump-sum purchase allocated)**  

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Grade A Plums (100 bu.) | 900 | |
| Inventory—Grade B Plums (300 bu.) | 1,350 | |
| Inventory—Grade C Plums (600 bu.) | 1,350 | |
| Cash | | 3,600 |
| *To record basket purchase + sorting; cost allocated by relative sales value* | | |

**Check:** Dr 900 + 1,350 + 1,350 = Cr 3,600. Balanced.

**c. Gross profit proof (if all units sold)**  

| Grade | Sales value | Allocated cost | Gross profit | GP% |
|---|---:|---:|---:|---:|
| A | $1,800 | $900 | $900 | 50% |
| B | 2,700 | 1,350 | 1,350 | 50% |
| C | 2,700 | 1,350 | 1,350 | 50% |
| **Total** | **$7,200** | **$3,600** | **$3,600** | **50%** |

**Key property:** Relative sales value allocation forces **identical GP%** across grades.

**d. September 22 — disposal (sale) and COGS**  

Sales revenue:  
- A: 70 × $18 = $1,260  
- B: 180 × $9 = $1,620  
- C: 400 × $4.50 = $1,800  
- **Total cash / sales = $4,680**

COGS (using allocated unit costs):  
- A: 70 × $9.00 = $630  
- B: 180 × $4.50 = $810  
- C: 400 × $2.25 = $900  
- **Total COGS = $2,340**

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 4,680 | |
| Sales Revenue | | 4,680 |
| *Cash sales of graded plums at retail* | | |

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 2,340 | |
| Inventory—Grade A Plums | | 630 |
| Inventory—Grade B Plums | | 810 |
| Inventory—Grade C Plums | | 900 |
| *Remove allocated cost of units sold* | | |

**Check:** Sale JE 4,680 = 4,680; COGS JE 2,340 = 630 + 810 + 900. Both balance.  
**Gross profit on actual sales:** $4,680 − $2,340 = **$2,340** (50% of sales).

**e. Ending inventory schedule (after Sept 22)**  

| Grade | Units remaining | Unit cost | Ending inventory |
|---|---:|---:|---:|
| A | 100 − 70 = 30 | $9.00 | **$270** |
| B | 300 − 180 = 120 | $4.50 | **$540** |
| C | 600 − 400 = 200 | $2.25 | **$450** |
| **Total** | | | **$1,260** |

**Rollforward check:** Beginning allocated inventory $3,600 − COGS $2,340 = ending inventory **$1,260**.

**Key insight:** The relative sales value method assigns the basket cost in proportion to each grade’s revenue-producing ability. Higher-priced grades absorb more of the lump-sum cost, but GP% is the same for every grade. After allocation, perpetual inventory tracking and COGS use those allocated unit costs.

### Q2 — CORE number variant — Hazelnut grades: recompute allocation, purchase JE, partial sale, EI
**LO:** LO 10-3  
**Concept:** Number-variant twin of relative sales value allocation, initial recognition, disposal, and ending inventory  
**Scenario:**  
Redwood Valley Nuts purchases **1,500 bags** of ungraded hazelnuts for **$11,200 cash** on **October 3**. Grading cost is **$800 cash**. Total cost to allocate = **$12,000**.

| Grade | Quantity (bags) | Unit sales price |
|---|---:|---:|
| Premium | 250 | $30 |
| Choice | 500 | $18 |
| Economy | 750 | $10 |

On **October 19**, Redwood Valley sells for cash: **150** Premium, **300** Choice, and **500** Economy at the listed prices. Perpetual inventory; relative sales value method.

**Required:**  
a. Allocation schedule (sales value, fraction, allocated cost, unit cost).  
b. October 3 purchase journal entry.  
c. October 19 sale and COGS journal entries.  
d. Ending inventory by grade after October 19.  
e. Prove total GP% on the October 19 sales equals the theoretical full-run GP%.

**Answer key:**  

**a. Allocation schedule**  

| Grade | Qty | Unit SP | Total SV | Fraction | Allocated cost | Unit cost |
|---|---:|---:|---:|---:|---:|---:|
| Premium | 250 | $30 | $7,500 | 7,500 / 24,000 = 0.3125 | **$3,750** | **$15.00** |
| Choice | 500 | $18 | $9,000 | 9,000 / 24,000 = 0.375 | **$4,500** | **$9.00** |
| Economy | 750 | $10 | $7,500 | 7,500 / 24,000 = 0.3125 | **$3,750** | **$5.00** |
| **Total** | **1,500** | | **$24,000** | **1.00** | **$12,000** | |

**Check:** $3,750 + $4,500 + $3,750 = $12,000.  
**Theoretical full-run GP%:** ($24,000 − $12,000) / $24,000 = **50%**.

**b. October 3 — initial recognition**  

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Premium Hazelnuts | 3,750 | |
| Inventory—Choice Hazelnuts | 4,500 | |
| Inventory—Economy Hazelnuts | 3,750 | |
| Cash | | 12,000 |

**Check:** Dr 12,000 = Cr 12,000.

**c. October 19 — sale and COGS**  

Sales: 150 × $30 + 300 × $18 + 500 × $10 = $4,500 + $5,400 + $5,000 = **$14,900**  
COGS: 150 × $15 + 300 × $9 + 500 × $5 = $2,250 + $2,700 + $2,500 = **$7,450**

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 14,900 | |
| Sales Revenue | | 14,900 |

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 7,450 | |
| Inventory—Premium Hazelnuts | | 2,250 |
| Inventory—Choice Hazelnuts | | 2,700 |
| Inventory—Economy Hazelnuts | | 2,500 |

**Check:** 14,900 = 14,900; 7,450 = 2,250 + 2,700 + 2,500.

**d. Ending inventory**  

| Grade | Units left | Unit cost | EI |
|---|---:|---:|---:|
| Premium | 100 | $15.00 | $1,500 |
| Choice | 200 | $9.00 | $1,800 |
| Economy | 250 | $5.00 | $1,250 |
| **Total** | | | **$4,550** |

**Rollforward:** $12,000 − $7,450 = **$4,550**.

**e. GP% proof on actual sales**  
GP = $14,900 − $7,450 = **$7,450**  
GP% = $7,450 / $14,900 = **50%** (matches full-run GP%).

**Key insight:** Changing quantities, prices, and total cost does not change the method: form sales-value fractions, multiply by total lump-sum cost, then use resulting unit costs for all later COGS and inventory measurements.

### Q3 — CORE alternate angle — Land lots: period-end COGS adjusting JE, inventory schedule, presentation
**LO:** LO 10-3  
**Concept:** Relative sales value for real-estate lot inventory; period-end adjusting JE to record COGS after sales already booked; subsequent measurement of remaining lots  
**Scenario:**  
Lakeshore Homes LLC purchases a tract of land for **$720,000 cash** on **March 1**. The tract is subdivided as follows:

- Common walkways, drainage, and open space (not sold as inventory lots; cost is absorbed in lot allocation).  
- **12 Lakeview lots** expected to sell for **$60,000** each.  
- **18 Meadow lots** expected to sell for **$40,000** each.  
- **24 Woods lots** expected to sell for **$20,000** each.

Lakeshore uses a perpetual inventory system and the relative sales value method. Treat each lot category as a separate inventory account.

During the year Lakeshore sells for cash: **8 Lakeview lots**, **12 Meadow lots**, and **16 Woods lots** at the listed prices. The bookkeeper **correctly recorded cash and Sales Revenue** for each sale during the year but **failed to record cost of goods sold** and the related inventory reductions.

At December 31, year-end, NRV exceeds allocated cost for all remaining lots (no LCNRV write-down).

**Required:**  
a. Prepare the relative sales value **allocation schedule** and the **March 1** purchase journal entry.  
b. Compute total **Sales Revenue** already recorded and the **period-end adjusting journal entry** needed at December 31 to recognize COGS and relieve inventory (by lot category).  
c. Prepare the **period-end inventory valuation schedule** by category after the adjusting entry. Confirm that no LCNRV write-down adjusting entry is required under the facts given.  
d. **Classification / presentation:** How should remaining lot inventory be reported on the year-end classified balance sheet? What amount? What amounts appear for Sales, COGS, and gross profit on the income statement for the year?

**Answer key:**  

**a. Allocation and March 1 purchase JE**  

| Category | Lots | Unit SP | Total SV | Fraction | Allocated cost | Cost per lot |
|---|---:|---:|---:|---:|---:|---:|
| Lakeview | 12 | $60,000 | $720,000 | 720,000 / 1,920,000 = 0.375 | **$270,000** | **$22,500** |
| Meadow | 18 | $40,000 | $720,000 | 720,000 / 1,920,000 = 0.375 | **$270,000** | **$15,000** |
| Woods | 24 | $20,000 | $480,000 | 480,000 / 1,920,000 = 0.25 | **$180,000** | **$7,500** |
| **Total** | **54** | | **$1,920,000** | **1.00** | **$720,000** | |

Public/common areas receive **no separate inventory balance**; their cost is included in the $720,000 and allocated entirely to salable lots via relative sales value.

| Account | Debit | Credit |
|---|---:|---:|
| Inventory—Lakeview Lots (12) | 270,000 | |
| Inventory—Meadow Lots (18) | 270,000 | |
| Inventory—Woods Lots (24) | 180,000 | |
| Cash | | 720,000 |
| *Lump-sum land purchase allocated to salable lots by relative sales value* | | |

**Check:** Dr 270,000 + 270,000 + 180,000 = Cr 720,000. Balanced.

**b. Sales already recorded and period-end adjusting JE**  

Sales revenue already recorded (cash sales at listed prices):  
- Lakeview: 8 × $60,000 = $480,000  
- Meadow: 12 × $40,000 = $480,000  
- Woods: 16 × $20,000 = $320,000  
- **Total Sales Revenue = $1,280,000**

COGS to recognize (allocated cost of lots sold):  
- Lakeview: 8 × $22,500 = $180,000  
- Meadow: 12 × $15,000 = $180,000  
- Woods: 16 × $7,500 = $120,000  
- **Total COGS = $480,000**

**December 31 — period-end adjusting entry (COGS / inventory relief):**  

| Account | Debit | Credit |
|---|---:|---:|
| Cost of Goods Sold | 480,000 | |
| Inventory—Lakeview Lots | | 180,000 |
| Inventory—Meadow Lots | | 180,000 |
| Inventory—Woods Lots | | 120,000 |
| *Period-end adjusting entry: remove allocated cost of lots sold during the year* | | |

**Check:** Dr 480,000 = Cr 180,000 + 180,000 + 120,000. Balanced.

(Note: The sales-side entries—Dr Cash, Cr Sales Revenue totaling $1,280,000—were already recorded during the year and are **not** re-recorded at year-end.)

**c. Period-end inventory schedule (subsequent measurement after adjusting entry)**  

| Category | Lots remaining | Cost per lot | Carrying amount |
|---|---:|---:|---:|
| Lakeview | 12 − 8 = 4 | $22,500 | **$90,000** |
| Meadow | 18 − 12 = 6 | $15,000 | **$90,000** |
| Woods | 24 − 16 = 8 | $7,500 | **$60,000** |
| **Total ending inventory** | | | **$240,000** |

**Rollforward:** $720,000 − $480,000 = **$240,000**.

**LCNRV period-end write-down:** **None required** under the given facts. Inventory remains at allocated **cost**. NRV exceeds cost for remaining lots, so no lower-of-cost-or-NRV write-down is indicated. (Relative sales value sets **initial cost**; LCNRV is a separate subsequent measurement rule from LO 10-1.)

**d. Classification / presentation**  
- Report **Inventory** (or Inventory—Real estate lots held for sale) as a **current asset** at the aggregate carrying amount **$240,000**, unless management’s operating cycle supports noncurrent classification for lots expected to sell beyond one year (exam default for lot inventory held for sale in the normal course: **current**).  
- Optional detail: Lakeview $90,000; Meadow $90,000; Woods $60,000.  
- Common areas are **not** a separate inventory line; their cost is already embedded in lot carrying amounts via relative sales value.  
- Income statement (after period-end adjusting entry): Sales **$1,280,000**, COGS **$480,000**, gross profit **$800,000**.  
- GP% on actual sales = $800,000 / $1,280,000 = **62.5%**, which equals the theoretical full-run GP% of ($1,920,000 − $720,000) / $1,920,000 = **62.5%**.

**Key insight:** Relative sales value allocation sets cost at purchase. When sales are recorded without concurrent COGS under perpetual inventory, the **period-end adjusting JE** is essential: Dr COGS / Cr Inventory for the **allocated cost** of units sold. Ending inventory is then remaining lots × allocated unit cost, with no separate public-space inventory.

### Q4 — MC (method / allocated amount)
**LO:** LO 10-3  
**Concept:** Identify relative sales value allocation and compute allocated cost for one inventory group  

**Question 1:**  
A packing plant acquires three grades of fruit in a single lump-sum purchase and incurs grading costs that are included in total inventoriable cost. Under the LO 10-3 relative sales value method, the lump-sum cost is assigned to each grade based on:

- A) Equal cost per bushel to every grade regardless of selling price  
- B) Each grade’s **relative expected sales value** (quantity × unit selling price) as a fraction of total expected sales value  
- C) Relative physical weight only  
- D) Replacement cost of each grade at the purchase date  

**Answer:** **B.** The relative sales value method allocates lump-sum cost in proportion to each type’s total expected sales value so cost follows economic utility / revenue-producing ability. Equal unit cost (A) ignores different benefits; weight alone (C) is not the LO 10-3 basis; replacement cost (D) is not the allocation base illustrated for basket inventory purchases.

---

**Question 2:**  
Prairie Ridge Development purchases land for **$900,000** cash and subdivides it into salable lots (common areas have no separate sales value; full cost is allocated to lots):

| Group | Number of lots | Price per lot |
|---|---:|---:|
| Ridge | 10 | $50,000 |
| Prairie | 20 | $40,000 |
| Glen | 20 | $25,000 |

Using the relative sales value method, the **allocated cost of Prairie** land inventory is:

- A) $400,000  
- B) $360,000  
- C) $300,000  
- D) $900,000  

**Answer:** **A. $400,000.**  
Sales values: Ridge = 10 × $50,000 = $500,000; Prairie = 20 × $40,000 = $800,000; Glen = 20 × $25,000 = $500,000; **total SV = $1,800,000**.  
Prairie fraction = $800,000 / $1,800,000 = 4/9.  
Allocated cost = (4/9) × $900,000 = **$400,000**.  

Distractors: B is an incorrect fraction applied to total cost; C would be if equal thirds of $900,000 were used ($300,000); D is total purchase price with no allocation. (Ridge and Glen each: $500,000 / $1,800,000 × $900,000 = **$250,000**.)
