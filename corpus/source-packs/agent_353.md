# Agent 353 — CORE DEMO — LO 13-6

**Chapter:** 13  
**LO title:** Account for impairment of indefinite life intangible assets and goodwill  
**Critical gap LO:** no  
**Emphasis angle:** period_end_adjusting_JE

## Concept list for this pack
- **No amortization** of indefinite-life intangibles or goodwill (public company); subsequent carrying amount changes only via **impairment** (or disposal)
- **Indefinite-life intangible impairment:** optional qualitative assessment (“more likely than not” impaired) → **quantitative test** compares **fair value to carrying amount**; loss = CA − FV; write asset down directly; **no subsequent reversal**
- **Goodwill impairment (public):** optional qualitative assessment on the **reporting unit** → quantitative test: impairment = **CA of reporting unit (incl. GW) − FV of reporting unit**, **limited to** goodwill allocated to that unit
- **Order of testing:** other assets / asset groups of the unit tested **before** goodwill when concurrent
- **Period-end adjusting JE (emphasis):** Dr Impairment Loss / Cr Trade Name (or Goodwill) at annual test date (or more often if indicators)
- **Initial recognition JE:** capitalize acquired indefinite-life intangible at cost; record residual **goodwill** in a business combination
- **Subsequent measurement schedule:** multi-period roll-forward (beg CA, amort = 0, impairment, end CA)
- **Disposal JE:** remove post-impairment carrying amount; gain/loss = proceeds − CA; report in income from continuing operations
- **Contrast (not LO 13-3 model):** indefinite-life / goodwill tests do **not** use the two-step recoverability (undiscounted cash flows) model used for finite-life intangibles

### Q1 — CORE — Trademark + goodwill life cycle: initial recognition, subsequent schedule, **period-end impairment AJs** (emphasis), disposal
**LO:** LO 13-6  
**Concept:** Period-end quantitative impairment adjusting entries for an indefinite-life trade name and for goodwill of a reporting unit; initial recognition; carrying-amount schedule; post-impairment disposal  
**Scenario:**  
**Northpine Outdoor Brands Inc.** is a **public**, calendar-year company. It does **not** elect the private-company goodwill amortization alternative.

**January 1, Year 1 — two events**

1. Northpine purchases an **indefinite-life trade name** from an unrelated party for **$180,000 cash**. Renewals are expected indefinitely at nominal cost; management concludes the useful life is **indefinite**.

2. Northpine acquires **100% of Summit Gear Co.** for **$420,000 cash**. Summit’s operations become Northpine’s **Alpine Division** (a **reporting unit**). Acquisition-date fair values:

| Account | Fair value |
|---|---:|
| Cash | $40,000 |
| Accounts receivable | 60,000 |
| Inventory | 70,000 |
| Property, plant, and equipment (net) | 310,000 |
| **Total identifiable assets** | **$480,000** |
| Accounts payable | 50,000 |
| Notes payable | 90,000 |
| **Total identifiable liabilities** | **$140,000** |

No separately identified Summit intangible is recorded beyond residual goodwill.  
Years 1 and early Year 2: qualitative assessments support **no** impairment of the trade name or Alpine goodwill (no quantitative losses recorded).

**December 31, Year 2 — annual impairment testing (emphasis)**  
Northpine **bypasses** qualitative assessment and performs quantitative tests directly:

| Item | Data |
|---|---|
| Trade name carrying amount | $180,000 |
| Trade name fair value (appraisal) | $145,000 |
| Alpine Division carrying amount of net assets **including goodwill** | $385,000 |
| Alpine Division fair value (appraisal) | $360,000 |
| Goodwill allocated to Alpine (carrying amount before Year-2 test) | $80,000 |

No other Alpine assets require impairment write-downs before the goodwill test.

**June 30, Year 3 — disposal**  
Northpine sells the trade name for **$138,000 cash**. No amortization was ever recorded on the trade name. The Year-2 impairment is the only carrying-amount change before sale.

**Required:**  
a. Compute **goodwill** recorded on January 1, Year 1.  
b. Prepare the **January 1, Year 1 initial recognition** journal entries for (1) the trade name purchase and (2) the Summit / Alpine acquisition. Prove each entry balances.  
c. Prepare a **subsequent measurement / carrying-amount schedule** for the trade name and goodwill from January 1, Year 1 through December 31, Year 2 (include amortization, if any, and Year-2 impairment).  
d. **(Emphasis)** Compute the Year-2 **impairment loss** on (1) the trade name and (2) Alpine goodwill. Prepare the **December 31, Year 2 period-end adjusting journal entries**.  
e. Prepare the **June 30, Year 3 disposal** journal entry for the trade name.  
f. State the December 31, Year 2 **balance-sheet carrying amounts** of the trade name and goodwill after the period-end adjustments.

**Answer key:**

**a. Goodwill at acquisition**

Fair value of identifiable net assets = $480,000 − $140,000 = **$340,000**

\[
\text{Goodwill} = \$420{,}000 - \$340{,}000 = \mathbf{\$80{,}000}
\]

**b. January 1, Year 1 — initial recognition JEs**

*(1) Trade name purchase*

| Account | Debit | Credit |
|---|---:|---:|
| Trade Name (indefinite life) | 180,000 | |
| Cash | | 180,000 |
| *Capitalize acquired indefinite-life trade name at cost* | | |

**Check:** Dr 180,000 = Cr 180,000. **Balanced.**

*(2) Summit acquisition → Alpine reporting unit*

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 40,000 | |
| Accounts Receivable | 60,000 | |
| Inventory | 70,000 | |
| Property, Plant, and Equipment | 310,000 | |
| Goodwill | 80,000 | |
| Accounts Payable | | 50,000 |
| Notes Payable | | 90,000 |
| Cash | | 420,000 |
| *Record Summit net assets at FV; residual to goodwill* | | |

**Check:**  
Dr = 40,000 + 60,000 + 70,000 + 310,000 + 80,000 = **560,000**  
Cr = 50,000 + 90,000 + 420,000 = **560,000**. **Balanced.**

**c. Subsequent measurement schedule (no amortization; impairment in Year 2)**

| Asset | 1/1/Y1 CA | Y1 amort. | 12/31/Y1 CA | Y2 amort. | Y2 impairment | 12/31/Y2 CA |
|---|---:|---:|---:|---:|---:|---:|
| Trade name (indefinite) | $180,000 | **$0** | $180,000 | **$0** | **$35,000** | **$145,000** |
| Goodwill—Alpine | 80,000 | **0** | 80,000 | **0** | **25,000** | **55,000** |

*Amortization column is zero because indefinite-life intangibles and public-company goodwill are not amortized.*

**d. December 31, Year 2 — period-end impairment measurements and AJs (emphasis)**

*(1) Indefinite-life trade name — quantitative test*

| | Amount |
|---|---:|
| Fair value of trade name | $145,000 |
| Less: carrying amount | 180,000 |
| **Impairment loss** | **$35,000** |

Because FV < CA, the asset is impaired. Loss = CA − FV = **$35,000**.

| Account | Debit | Credit |
|---|---:|---:|
| Impairment Loss—Trade Name | 35,000 | |
| Trade Name | | 35,000 |
| *Period-end quantitative impairment of indefinite-life trade name* | | |

**Check:** Dr 35,000 = Cr 35,000. **Balanced.**  
New accounting basis of trade name = **$145,000**. Subsequent reversal is prohibited.

*(2) Goodwill—Alpine Division — quantitative test*

| | Amount |
|---|---:|
| Fair value of Alpine reporting unit | $360,000 |
| Less: carrying amount of Alpine (incl. goodwill) | 385,000 |
| Excess of CA over FV | $25,000 |
| Goodwill allocated to Alpine | 80,000 |
| **Goodwill impairment loss** (lesser of excess and GW) | **$25,000** |

| Account | Debit | Credit |
|---|---:|---:|
| Impairment Loss—Goodwill | 25,000 | |
| Goodwill | | 25,000 |
| *Period-end goodwill impairment: RU CA exceeds RU FV by $25,000 (≤ $80,000 GW)* | | |

**Check:** Dr 25,000 = Cr 25,000. **Balanced.**  
Full $25,000 reduces goodwill (loss does not exceed GW balance). Ending goodwill = **$55,000**.

**Total Year-2 impairment loss** = $35,000 + $25,000 = **$60,000**.

**e. June 30, Year 3 — disposal of trade name**

Carrying amount at sale = post-impairment basis **$145,000**.  
Proceeds $138,000 − CA $145,000 = **$7,000 loss**.

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 138,000 | |
| Loss on Disposal of Trade Name | 7,000 | |
| Trade Name | | 145,000 |
| *Derecognize indefinite-life trade name; loss = proceeds − CA* | | |

**Check:** Dr 138,000 + 7,000 = 145,000 = Cr 145,000. **Balanced.**

**f. December 31, Year 2 balance-sheet amounts (after AJs)**

| Asset | Carrying amount |
|---|---:|
| Trade name (indefinite-life intangible) | **$145,000** |
| Goodwill (separate line) | **$55,000** |

**Key insight:** Indefinite-life intangibles and goodwill are **not amortized**; the core period-end work is the **quantitative impairment AJ** (FV vs CA for the asset; RU FV vs RU CA for goodwill, capped at GW). Post-impairment CA is the new basis used for later disposal.

### Q2 — CORE number variant — Brand, goodwill cap edge, multi-year schedule, period-end AJs, disposal with gain
**LO:** LO 13-6  
**Concept:** Number-variant twin: initial recognition of brand and residual goodwill; subsequent zero-amortization schedule with Year-3 period-end impairments; disposal of brand after impairment  
**Scenario:**  
**Lakeshore Consumer Brands Corp.** is a **public**, calendar-year company (no private-company GW amortization election).

**March 1, Year 1**  
Lakeshore purchases an **indefinite-life brand name** for **$240,000 cash**.

**January 1, Year 2**  
Lakeshore acquires **100% of HarborSoap LLC** for **$560,000 cash**. HarborSoap becomes the **Personal Care reporting unit**. Acquisition-date fair values of identifiable net assets:

| | Fair value |
|---|---:|
| Identifiable assets | $600,000 |
| Identifiable liabilities | 160,000 |
| **Identifiable net assets** | **$440,000** |

(For the acquisition entry, treat identifiable assets as a single **Net Identifiable Assets** control total of $440,000, or expand as: Cash $55,000; Receivables $95,000; Inventory $110,000; PPE $340,000 = $600,000 assets; Payables $70,000; Long-term debt $90,000 = $160,000 liabilities.)

Years 1–2: no impairment losses on the brand or Personal Care goodwill.

**December 31, Year 3 — quantitative tests (bypass qualitative)**

| Item | Amount |
|---|---:|
| Brand name carrying amount | $240,000 |
| Brand name fair value | $195,000 |
| Personal Care RU carrying amount (incl. goodwill) | $510,000 |
| Personal Care RU fair value | $475,000 |
| Goodwill allocated to Personal Care (before Year-3 test) | $120,000 |

No other Personal Care assets are written down before the goodwill test.

**September 15, Year 4**  
Lakeshore sells the brand name for **$200,000 cash**.

**Required:**  
a. Compute goodwill on January 1, Year 2.  
b. Record initial recognition JEs: (1) March 1, Year 1 brand purchase; (2) January 1, Year 2 HarborSoap acquisition (use the expanded asset/liability fair values).  
c. Prepare a **subsequent measurement schedule** for brand and goodwill from acquisition through December 31, Year 3.  
d. **(Emphasis)** Compute Year-3 impairment losses and record **December 31, Year 3 period-end adjusting entries**.  
e. Record the **September 15, Year 4 disposal** of the brand.  
f. What is the **maximum** goodwill impairment that could ever be recognized for Personal Care given the $120,000 GW balance (concept check)?

**Answer key:**

**a. Goodwill**

\[
\text{Goodwill} = \$560{,}000 - \$440{,}000 = \mathbf{\$120{,}000}
\]

**b. Initial recognition JEs**

*(1) March 1, Year 1 — brand*

| Account | Debit | Credit |
|---|---:|---:|
| Brand Name (indefinite life) | 240,000 | |
| Cash | | 240,000 |
| *Acquire indefinite-life brand at cost* | | |

**Check:** Dr = Cr = 240,000. **Balanced.**

*(2) January 1, Year 2 — HarborSoap / Personal Care*

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 55,000 | |
| Accounts Receivable | 95,000 | |
| Inventory | 110,000 | |
| Property, Plant, and Equipment | 340,000 | |
| Goodwill | 120,000 | |
| Accounts Payable | | 70,000 |
| Long-Term Debt | | 90,000 |
| Cash | | 560,000 |
| *Record HarborSoap at FV; residual goodwill $120,000* | | |

**Check:**  
Dr = 55,000 + 95,000 + 110,000 + 340,000 + 120,000 = **720,000**  
Cr = 70,000 + 90,000 + 560,000 = **720,000**. **Balanced.**

**c. Subsequent measurement schedule**

| Asset | Initial CA | Through 12/31/Y2 amort. | 12/31/Y2 CA | Y3 amort. | Y3 impairment | 12/31/Y3 CA |
|---|---:|---:|---:|---:|---:|---:|
| Brand name | $240,000 (3/1/Y1) | **$0** | $240,000 | **$0** | **$45,000** | **$195,000** |
| Goodwill—Personal Care | 120,000 (1/1/Y2) | **0** | 120,000 | **0** | **35,000** | **85,000** |

**d. December 31, Year 3 — period-end impairment AJs (emphasis)**

*(1) Brand name*

Impairment = $240,000 − $195,000 = **$45,000**

| Account | Debit | Credit |
|---|---:|---:|
| Impairment Loss—Brand Name | 45,000 | |
| Brand Name | | 45,000 |
| *Quantitative test: FV $195,000 < CA $240,000* | | |

**Check:** Dr = Cr = 45,000. **Balanced.**

*(2) Goodwill—Personal Care*

| | Amount |
|---|---:|
| RU fair value | $475,000 |
| RU carrying amount (incl. GW) | 510,000 |
| Excess of CA over FV | **$35,000** |
| Cap at goodwill balance | 120,000 |
| **Impairment loss** | **$35,000** |

| Account | Debit | Credit |
|---|---:|---:|
| Impairment Loss—Goodwill | 35,000 | |
| Goodwill | | 35,000 |
| *RU CA exceeds RU FV by $35,000; loss ≤ GW of $120,000* | | |

**Check:** Dr = Cr = 35,000. **Balanced.**  
Ending goodwill = $120,000 − $35,000 = **$85,000**.  
**Total Year-3 impairment** = $45,000 + $35,000 = **$80,000**.

**e. September 15, Year 4 — disposal of brand**

CA at disposal = **$195,000**.  
Gain = $200,000 − $195,000 = **$5,000**.

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 200,000 | |
| Brand Name | | 195,000 |
| Gain on Disposal of Brand Name | | 5,000 |
| *Derecognize post-impairment brand CA; proceeds exceed CA* | | |

**Check:** Dr 200,000 = Cr 195,000 + 5,000. **Balanced.**

**f. Maximum goodwill impairment for Personal Care**  
**$120,000** — the entire allocated goodwill balance. The excess of RU CA over RU FV cannot create a loss larger than GW (cannot write identifiable net assets below zero via the goodwill test alone).

**Key insight:** Same LO 13-6 mechanics as Q1 with new numbers; disposal can produce a **gain** if post-impairment FV/proceeds recover. Always **cap** goodwill impairment at the GW balance.

### Q3 — CORE alternate angle — Period-end only: no-impairment, full GW write-off (cap), qualitative bypass, disposal
**LO:** LO 13-6  
**Concept:** Period-end adjusting entries under edge cases — FV ≥ CA (no loss); goodwill impairment **capped** at GW when RU shortfall exceeds GW; qualitative assessment that stops testing; disposal of indefinite-life asset  
**Scenario:**  
**Westfield Precision Instruments Inc.** (public, calendar year) holds the following at **December 31, Year 4** (all amounts already on the books; no amortizations apply):

| Item | Carrying amount | Other data |
|---|---:|---|
| Trade name A (indefinite) | $92,000 | Fair value $98,000; management performs quantitative test |
| Trade name B (indefinite) | $70,000 | Qualitative assessment: **not** more likely than not that the asset is impaired; management does **not** elect to bypass qualitative |
| Goodwill—Sensors Division | $48,000 | Sensors RU CA (incl. GW) **$265,000**; Sensors RU FV **$210,000**; other assets already tested — no further write-downs needed before GW test |

On **January 20, Year 5**, Westfield sells **Trade name A** for **$90,000 cash** (after any Year-4 impairment entries, if any).

**Required:**  
a. For **each** of Trade name A, Trade name B, and Sensors goodwill, determine the **December 31, Year 4 impairment loss** (if any) and explain the testing path.  
b. **(Emphasis)** Prepare all **period-end adjusting journal entries** required on December 31, Year 4. If no entry is required for an item, state “no entry” and why.  
c. Prepare a brief **impairment testing summary schedule** (item, CA, FV or RU data, loss, ending CA).  
d. Prepare the **January 20, Year 5 disposal** entry for Trade name A.  
e. Suppose instead Sensors RU FV were **$250,000** (CA still $265,000). What would the goodwill impairment be?

**Answer key:**

**a. Impairment determinations**

**(1) Trade name A — quantitative**  
FV $98,000 **>** CA $92,000 → **not impaired**. Impairment loss = **$0**.  
*(Indefinite-life quantitative test is a one-step FV vs CA comparison; no recoverability step.)*

**(2) Trade name B — qualitative only**  
Qualitative conclusion: **not** more likely than not impaired → **stop**. No quantitative test; impairment loss = **$0**. No fair value estimate required.

**(3) Goodwill—Sensors Division — quantitative**

| | Amount |
|---|---:|
| RU fair value | $210,000 |
| RU carrying amount (incl. GW) | 265,000 |
| Excess of CA over FV | **$55,000** |
| Goodwill balance | 48,000 |
| **Impairment loss** = min($55,000, $48,000) | **$48,000** |

The entire goodwill balance is written off. The $7,000 residual excess is **not** recognized as an additional loss under the goodwill test (it is not allocated to write down other assets in this test).

**b. December 31, Year 4 — period-end AJs (emphasis)**

*Trade name A:* **No entry** (FV ≥ CA).

*Trade name B:* **No entry** (qualitative assessment does not indicate more-likely-than-not impairment).

*Sensors goodwill:*

| Account | Debit | Credit |
|---|---:|---:|
| Impairment Loss—Goodwill | 48,000 | |
| Goodwill | | 48,000 |
| *Full write-off: RU shortfall $55,000 capped at GW $48,000* | | |

**Check:** Dr 48,000 = Cr 48,000. **Balanced.**  
Ending Sensors goodwill = **$0**.

**c. Impairment testing summary schedule**

| Item | Pre-test CA | Test path | Benchmark | Loss | Ending CA |
|---|---:|---|---|---:|---:|
| Trade name A | $92,000 | Quantitative | FV $98,000 | **$0** | $92,000 |
| Trade name B | 70,000 | Qualitative only | Not MLN impaired | **$0** | 70,000 |
| Goodwill—Sensors | 48,000 | Quantitative | RU FV $210k vs CA $265k | **$48,000** | **$0** |

**d. January 20, Year 5 — disposal of Trade name A**

CA still **$92,000** (no Year-4 impairment).  
Loss = $92,000 − $90,000 = **$2,000**.

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 90,000 | |
| Loss on Disposal of Trade Name | 2,000 | |
| Trade Name A | | 92,000 |
| *Derecognize trade name; proceeds < CA* | | |

**Check:** Dr 90,000 + 2,000 = 92,000 = Cr. **Balanced.**

**e. Alternate Sensors FV $250,000**  
Excess = $265,000 − $250,000 = **$15,000** < GW $48,000 → impairment = **$15,000**; ending GW = **$33,000**.

**Key insight:** Period-end LO 13-6 work is **not always a write-down** — FV above CA or a “clean” qualitative assessment yields **no JE**. When RU shortfall **exceeds** goodwill, impair **only to zero GW**, not more.

### Q4 — MC — Measurement of goodwill impairment loss
**LO:** LO 13-6  
**Concept:** Quantitative goodwill impairment amount = excess of reporting-unit CA over RU FV, limited to allocated goodwill  
**Question:**  
**Ironclad Logistics Inc.** (public) has a **Fleet Services** reporting unit with the following December 31 amounts after testing other assets of the unit:

- Carrying amount of Fleet Services net assets **including goodwill**: **$400,000**  
- Fair value of Fleet Services reporting unit: **$340,000**  
- Goodwill allocated to Fleet Services: **$75,000**

Management bypasses the qualitative assessment. What **goodwill impairment loss**, if any, should Ironclad recognize?

- A) $0, because undiscounted future cash flows were not compared to carrying amount  
- B) $60,000  
- C) $75,000  
- D) $60,000 only if a recoverability test is failed first; otherwise $0  

**Answer:** **B.**  
Quantitative goodwill impairment = excess of RU carrying amount over RU fair value = $400,000 − $340,000 = **$60,000**. The loss is limited to allocated goodwill ($75,000), so the recognized loss is **$60,000** (not $75,000).  
A and D incorrectly import the **finite-life / PPE recoverability** (undiscounted cash flow) model from ASC 360 / LO 13-3; goodwill uses the ASC 350 **one-step** RU FV vs RU CA model. C would apply only if the excess were ≥ $75,000 (e.g., FV ≤ $325,000).

### Q5 — MC — Indefinite-life impairment model vs finite-life model
**LO:** LO 13-6  
**Concept:** Classification of impairment testing model — indefinite-life one-step FV vs CA (optional qualitative first); not the finite-life recoverability test  
**Question:**  
Which statement best describes **annual impairment testing of an indefinite-life trade name** under U.S. GAAP (ASC 350)?

- A) Amortize the trade name over 10 years, then test residual carrying amount only when a triggering event occurs  
- B) Optional qualitative assessment; if more likely than not impaired (or if qualitative is bypassed), compare fair value to carrying amount and recognize any excess of CA over FV as a loss  
- C) Always perform a recoverability test using undiscounted cash flows; measure loss only if undiscounted cash flows are less than carrying amount  
- D) Remeasure the trade name to fair value each period through OCI, similar to AFS debt securities  

**Answer:** **B.**  
Indefinite-life intangibles are **not amortized** (so A is wrong for public-company core path). They are tested at least annually via optional **qualitative** assessment and, when required, a **quantitative** FV-vs-CA test; loss = CA − FV.  
C is the **finite-life** (and PPE) model (LO 13-3 / ASC 360). D confuses indefinite-life cost model (with impairment) with investment accounting / crypto FV-NI (LO 13-5 path for crypto only).
