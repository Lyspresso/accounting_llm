# Agent 334 — CORE DEMO — LO 11-7

**Chapter:** 11  
**LO title:** Account for disposal of property, plant, and equipment  
**Critical gap LO:** no  
**Emphasis angle:** period_end_adjusting_JE

## Concept list for this pack
- **Voluntary** disposal (sale, exchange, abandonment) or **involuntary** disposal (casualty, eminent domain) — both recognize gain or loss
- **Update depreciation** (and related accruals) **through the disposal date** before removing the asset (**period-end / partial-period adjusting JE — emphasis**)
- **Derecognize** original cost and related **accumulated depreciation**
- **Gain or loss** = disposal proceeds (cash, receivable, insurance recovery, etc.) − **updated carrying amount**
- Gain/loss is reported in **income from continuing operations** (not typically discontinued operations solely because of PPE disposal)
- **Involuntary conversion:** gain or loss is still recognized even if proceeds will be reinvested in a replacement asset (ASC 610-30)
- Full demo path: **initial recognition** → **subsequent measurement / dep schedule** → **period-end (or disposal-date) adjusting JE** → **disposal JE**
- **Number-variant twin:** same path with all companies and amounts changed

### Q1 — CORE — Meridian Tool Works: purchase, dep schedule, partial-period AJ at disposal, gain on sale

**LO:** LO 11-7  
**Concept:** Initial recognition of equipment cost; multi-year subsequent depreciation schedule; **partial-period adjusting JE** to update accum. dep. through disposal date (emphasis); sale disposal JE with **gain**  
**Scenario:**  
**Meridian Tool Works, Inc.** (calendar-year) acquires a CNC finishing machine and later sells it mid-year. Straight-line depreciation is used. Depreciation was last updated on **December 31, 20X4**.

**January 1, 20X1 — acquisition costs paid in cash:**

| Component | Amount |
|---|---:|
| Invoice price | $54,000 |
| Freight-in | 1,800 |
| Installation and testing | 2,200 |
| **Total capitalized cost** | **$58,000** |

- Estimated residual value: **$4,000**  
- Estimated useful life: **6 years**  
- Depreciation method: **straight-line**  
- On **July 1, 20X5**, Meridian sells the machine for **$22,000 cash**. No selling costs.

**Required:**  
(a) Record the **January 1, 20X1 initial recognition JE** for the machine (prove Dr = Cr). State depreciable base and annual depreciation.  
(b) Prepare a **subsequent measurement (depreciation) schedule** for full years **20X1–20X4** showing annual depreciation, ending accumulated depreciation, and ending book value.  
(c) Record the **December 31, 20X4 period-end adjusting JE** for depreciation (emphasis on year-end AJ pattern).  
(d) Record the **July 1, 20X5 partial-period adjusting JE** updating depreciation through the disposal date (emphasis).  
(e) Compute updated accumulated depreciation, carrying amount, and gain or loss. Record the **July 1, 20X5 disposal JE**. Prove Dr = Cr.  
(f) **Classification:** Where is the gain (or loss) reported on the income statement?

**Answer key:**

**(a) January 1, 20X1 — initial recognition**

Capitalized cost = \(54{,}000 + 1{,}800 + 2{,}200 = \mathbf{\$58{,}000}\).

| Account | Debit | Credit |
|---|---:|---:|
| Equipment—CNC Finishing Machine | 58,000 | |
| Cash | | 58,000 |
| *Capitalize invoice, freight, and installation* | | |

**Check:** Dr 58,000 = Cr 58,000. **Balanced.**

Depreciable base = \(58{,}000 - 4{,}000 = \mathbf{\$54{,}000}\).  
Annual depreciation = \(54{,}000 / 6 = \mathbf{\$9{,}000}\).  
Monthly depreciation = \(9{,}000 / 12 = \mathbf{\$750}\).

**(b) Subsequent measurement schedule — full years 20X1–20X4**

| Year | Beg. book value | Depreciation expense | End. accum. dep. | End. book value |
|---|---:|---:|---:|---:|
| 20X1 | $58,000 | $9,000 | $9,000 | $49,000 |
| 20X2 | 49,000 | 9,000 | 18,000 | 40,000 |
| 20X3 | 40,000 | 9,000 | 27,000 | 31,000 |
| 20X4 | 31,000 | 9,000 | **36,000** | **22,000** |

Proof: \(4 \times 9{,}000 = \mathbf{\$36{,}000}\) accum. dep. at Dec 31, 20X4; BV \(58{,}000 - 36{,}000 = \mathbf{\$22{,}000}\).

**(c) December 31, 20X4 — period-end adjusting JE**

| Account | Debit | Credit |
|---|---:|---:|
| Depreciation Expense | 9,000 | |
| Accumulated Depreciation—Equipment | | 9,000 |
| *Year-end SL depreciation for 20X4* | | |

**Check:** Dr 9,000 = Cr 9,000. **Balanced.**

**(d) July 1, 20X5 — partial-period adjusting JE (emphasis — update through disposal date)**

Six months of use in 20X5 before sale: \(9{,}000 \times 6/12 = \mathbf{\$4{,}500}\) (or \(750 \times 6\)).

| Account | Debit | Credit |
|---|---:|---:|
| Depreciation Expense | 4,500 | |
| Accumulated Depreciation—Equipment | | 4,500 |
| *Update depreciation through July 1 disposal date* | | |

**Check:** Dr 4,500 = Cr 4,500. **Balanced.**

**(e) Disposal computation and JE**

Updated accum. dep. = \(36{,}000 + 4{,}500 = \mathbf{\$40{,}500}\).  
Carrying amount = \(58{,}000 - 40{,}500 = \mathbf{\$17{,}500}\).  
Gain on sale = \(22{,}000 - 17{,}500 = \mathbf{\$4{,}500}\).

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 22,000 | |
| Accumulated Depreciation—Equipment | 40,500 | |
| Gain on Disposal of Equipment | | 4,500 |
| Equipment—CNC Finishing Machine | | 58,000 |
| *Remove asset and accum. dep.; recognize gain* | | |

**Check:** Dr \(22{,}000 + 40{,}500 = 62{,}500\); Cr \(4{,}500 + 58{,}000 = 62{,}500\). **Balanced.**

**(f) Classification**  
The **$4,500 gain** is reported in the income statement as part of **income from continuing operations** (typically other income/expense), not as a capital contribution or deferred credit.

**Key insight:** Always **update depreciation to the disposal date** first; only then remove cost and accum. dep. Gain/loss equals **proceeds − updated book value**.

### Q2 — CORE number variant — Lakeshore Packaging: mid-year purchase, dep schedule, partial-period AJ, loss on sale

**LO:** LO 11-7  
**Concept:** Number-variant twin — initial recognition with capitalizable costs; multi-period dep schedule from a mid-year placed-in-service date; **partial-period adjusting JE** at disposal (emphasis); sale disposal JE with **loss**  
**Scenario:**  
**Lakeshore Packaging LLC** (calendar-year) places packaging equipment in service mid-year and later sells it at a loss. Straight-line depreciation. Depreciation was last updated on **December 31, 20X4**.

**April 1, 20X2 — acquisition costs paid in cash:**

| Component | Amount |
|---|---:|
| Invoice price | $70,000 |
| Freight-in | 2,500 |
| Installation and calibration | 2,500 |
| **Total capitalized cost** | **$75,000** |

- Estimated residual value: **$3,000**  
- Estimated useful life: **5 years**  
- Depreciation method: **straight-line**  
- On **October 1, 20X5**, Lakeshore sells the equipment for **$18,000 cash**. No selling costs.

**Required:**  
(a) Record the **April 1, 20X2 initial recognition JE**. Compute annual and monthly depreciation.  
(b) Prepare a **subsequent measurement schedule** from placement through **December 31, 20X4** (partial first year, then full years).  
(c) Record the **December 31, 20X4 period-end adjusting JE**.  
(d) Record the **October 1, 20X5 partial-period adjusting JE** (emphasis).  
(e) Compute updated accum. dep., carrying amount, and gain or loss. Record the **October 1, 20X5 disposal JE**. Prove Dr = Cr.  
(f) Briefly state how the answer would change if fair value (and cash proceeds) were **zero** (abandonment / scrap with no recovery).

**Answer key:**

**(a) April 1, 20X2 — initial recognition**

Capitalized cost = \(70{,}000 + 2{,}500 + 2{,}500 = \mathbf{\$75{,}000}\).

| Account | Debit | Credit |
|---|---:|---:|
| Equipment—Packaging Line | 75,000 | |
| Cash | | 75,000 |
| *Capitalize invoice, freight, and installation* | | |

**Check:** Dr 75,000 = Cr 75,000. **Balanced.**

Depreciable base = \(75{,}000 - 3{,}000 = \mathbf{\$72{,}000}\).  
Annual depreciation = \(72{,}000 / 5 = \mathbf{\$14{,}400}\).  
Monthly depreciation = \(14{,}400 / 12 = \mathbf{\$1{,}200}\).

**(b) Subsequent measurement schedule through Dec 31, 20X4**

| Period | Months | Depreciation expense | End. accum. dep. | End. book value |
|---|---:|---:|---:|---:|
| 20X2 (Apr 1–Dec 31) | 9 | $10,800 | $10,800 | $64,200 |
| 20X3 | 12 | 14,400 | 25,200 | 49,800 |
| 20X4 | 12 | 14,400 | **39,600** | **35,400** |

Proof months through Dec 31, 20X4: \(9 + 12 + 12 = 33\); \(33 \times 1{,}200 = \mathbf{\$39{,}600}\).  
BV: \(75{,}000 - 39{,}600 = \mathbf{\$35{,}400}\).

**(c) December 31, 20X4 — period-end adjusting JE**

| Account | Debit | Credit |
|---|---:|---:|
| Depreciation Expense | 14,400 | |
| Accumulated Depreciation—Equipment | | 14,400 |
| *Year-end SL depreciation for 20X4* | | |

**Check:** Dr 14,400 = Cr 14,400. **Balanced.**

**(d) October 1, 20X5 — partial-period adjusting JE (emphasis)**

Nine months of use in 20X5 before sale: \(1{,}200 \times 9 = \mathbf{\$10{,}800}\).

| Account | Debit | Credit |
|---|---:|---:|
| Depreciation Expense | 10,800 | |
| Accumulated Depreciation—Equipment | | 10,800 |
| *Update depreciation through October 1 disposal date* | | |

**Check:** Dr 10,800 = Cr 10,800. **Balanced.**

**(e) Disposal computation and JE**

Updated accum. dep. = \(39{,}600 + 10{,}800 = \mathbf{\$50{,}400}\).  
(Months total: \(33 + 9 = 42\); \(42 \times 1{,}200 = 50{,}400\).)  
Carrying amount = \(75{,}000 - 50{,}400 = \mathbf{\$24{,}600}\).  
**Loss** on sale = \(24{,}600 - 18{,}000 = \mathbf{\$6{,}600}\).

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 18,000 | |
| Accumulated Depreciation—Equipment | 50,400 | |
| Loss on Disposal of Equipment | 6,600 | |
| Equipment—Packaging Line | | 75,000 |
| *Remove asset and accum. dep.; recognize loss* | | |

**Check:** Dr \(18{,}000 + 50{,}400 + 6{,}600 = 75{,}000\); Cr \(75{,}000\). **Balanced.**

**(f) Abandonment with zero proceeds**  
Same **$10,800** partial-period update first. Then:

| Account | Debit | Credit |
|---|---:|---:|
| Accumulated Depreciation—Equipment | 50,400 | |
| Loss on Disposal of Equipment | 24,600 | |
| Equipment—Packaging Line | | 75,000 |
| *Write off fully updated carrying amount; no proceeds* | | |

**Check:** Dr \(50{,}400 + 24{,}600 = 75{,}000\). **Balanced.** Loss equals the **entire updated book value** of **$24,600**.

**Key insight:** Mid-year placement only changes **months of depreciation** in the schedule; the disposal sequence is unchanged: **update dep → remove cost & AD → plug gain/loss**.

### Q3 — CORE alternate angle — Northwind Logistics: period-end AJ emphasis, three disposal scenarios (gain / loss / involuntary), presentation

**LO:** LO 11-7  
**Concept:** **Period-end adjusting JE** emphasis (annual dep true-up and disposal-date update); disposal under **sale-with-loss**, **sale-with-gain**, and **involuntary casualty** (with and without insurance); income-statement classification  
**Scenario:**  
**Northwind Logistics, Inc.** (calendar-year) owns a forklift fleet asset with the following history. Straight-line depreciation. **Depreciation was last updated on December 31, 20X8.**

**January 1, 20X5 — purchase for cash:**  
- Capitalized cost: **$80,000**  
- Residual value: **$8,000**  
- Useful life: **8 years**  
- Annual SL depreciation: \((80{,}000 - 8{,}000) / 8 = \mathbf{\$9{,}000}\)  
- Monthly: **$750**

On **July 1, 20X9**, Northwind disposes of the asset under **three independent scenarios** (treat each as separate):

| Scenario | Facts |
|---|---|
| **A** | Sold for **$34,000 cash** |
| **B** | Sold for **$48,000 cash** |
| **C** | Destroyed in a warehouse flood; **no insurance recovery** expected |
| **D** *(extension)* | Destroyed by fire; insurer pays **$30,000 cash** the same day |

**Required:**  
(a) Prepare the **subsequent measurement rollforward** of accum. dep. and book value from **January 1, 20X5 through December 31, 20X8**.  
(b) **(Emphasis)** Record the **December 31, 20X8 period-end adjusting JE** for depreciation.  
(c) **(Emphasis)** Record the **July 1, 20X9 partial-period adjusting JE** common to all scenarios. Compute updated accum. dep. and book value.  
(d) Record the **disposal JE** for scenarios **A**, **B**, and **C**. Prove each balances.  
(e) Record scenario **D** (involuntary conversion with partial insurance recovery). Does reinvestment of the $30,000 in a replacement forklift change recognition of the loss?  
(f) **Classification:** State how gains/losses from voluntary vs involuntary disposals are reported.

**Answer key:**

**(a) Subsequent measurement through Dec 31, 20X8**

Full years of use: 20X5, 20X6, 20X7, 20X8 → **4 years**.

| Date | Depreciation for period | Accum. dep. | Book value |
|---|---:|---:|---:|
| 1/1/20X5 | — | $0 | $80,000 |
| 12/31/20X5 | 9,000 | 9,000 | 71,000 |
| 12/31/20X6 | 9,000 | 18,000 | 62,000 |
| 12/31/20X7 | 9,000 | 27,000 | 53,000 |
| **12/31/20X8** | **9,000** | **36,000** | **44,000** |

Proof: \(4 \times 9{,}000 = \mathbf{\$36{,}000}\) AD; BV \(80{,}000 - 36{,}000 = \mathbf{\$44{,}000}\).

**(b) December 31, 20X8 — period-end adjusting JE (emphasis)**

| Account | Debit | Credit |
|---|---:|---:|
| Depreciation Expense | 9,000 | |
| Accumulated Depreciation—Equipment | | 9,000 |
| *Year-end SL depreciation for 20X8* | | |

**Check:** Dr 9,000 = Cr 9,000. **Balanced.**

**(c) July 1, 20X9 — partial-period adjusting JE (emphasis; common to all scenarios)**

Six months: \(9{,}000 \times 6/12 = \mathbf{\$4{,}500}\).

| Account | Debit | Credit |
|---|---:|---:|
| Depreciation Expense | 4,500 | |
| Accumulated Depreciation—Equipment | | 4,500 |
| *Update depreciation through July 1 disposal / casualty date* | | |

**Check:** Dr 4,500 = Cr 4,500. **Balanced.**

Updated accum. dep. = \(36{,}000 + 4{,}500 = \mathbf{\$40{,}500}\).  
Updated book value = \(80{,}000 - 40{,}500 = \mathbf{\$39{,}500}\).

**(d) Disposal JEs**

**Scenario A — sold for $34,000 (loss)**  
Loss = \(39{,}500 - 34{,}000 = \mathbf{\$5{,}500}\).

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 34,000 | |
| Accumulated Depreciation—Equipment | 40,500 | |
| Loss on Disposal of Equipment | 5,500 | |
| Equipment | | 80,000 |
| *Sale below updated book value* | | |

**Check:** Dr \(34{,}000 + 40{,}500 + 5{,}500 = 80{,}000\). **Balanced.**

**Scenario B — sold for $48,000 (gain)**  
Gain = \(48{,}000 - 39{,}500 = \mathbf{\$8{,}500}\).

| Account | Debit | Credit |
|---|---:|---:|
| Cash | 48,000 | |
| Accumulated Depreciation—Equipment | 40,500 | |
| Gain on Disposal of Equipment | | 8,500 |
| Equipment | | 80,000 |
| *Sale above updated book value* | | |

**Check:** Dr \(48{,}000 + 40{,}500 = 88{,}500\); Cr \(8{,}500 + 80{,}000 = 88{,}500\). **Balanced.**

**Scenario C — flood; no insurance (involuntary; full write-off of BV)**  
Loss = entire updated book value = **$39,500**.

| Account | Debit | Credit |
|---|---:|---:|
| Accumulated Depreciation—Equipment | 40,500 | |
| Loss on Disposal of Equipment | 39,500 | |
| Equipment | | 80,000 |
| *Involuntary disposal; no recovery* | | |

**Check:** Dr \(40{,}500 + 39{,}500 = 80{,}000\). **Balanced.**

**(e) Scenario D — fire with $30,000 insurance recovery**

Loss = \(39{,}500 - 30{,}000 = \mathbf{\$9{,}500}\).

| Account | Debit | Credit |
|---|---:|---:|
| Cash (insurance proceeds) | 30,000 | |
| Accumulated Depreciation—Equipment | 40,500 | |
| Loss on Disposal of Equipment | 9,500 | |
| Equipment | | 80,000 |
| *Involuntary conversion; partial monetary recovery* | | |

**Check:** Dr \(30{,}000 + 40{,}500 + 9{,}500 = 80{,}000\). **Balanced.**

**Reinvestment:** Under ASC 610-30, involuntary conversion of a nonmonetary asset to a monetary asset is a **monetary transaction**. Gain or loss is **recognized even if** Northwind reinvests (or is obligated to reinvest) the proceeds in a replacement forklift. Replacement would be a **separate** acquisition entry at its cost.

**(f) Classification**  
Gains and losses on **both voluntary and involuntary** PPE disposals are reported in **income from continuing operations**. The casualty nature does not, by itself, reclassify the amount out of continuing operations.

**Key insight:** The **same** partial-period adjusting JE and updated book value feed **every** disposal form; only the **proceeds** (cash sale, zero recovery, or insurance) change the plug for gain or loss.

### Q4 — MC (classification / method) — disposal timing and presentation

**LO:** LO 11-7  
**Concept:** Classification of disposal gain/loss and requirement to update depreciation through disposal date  

**Question 1:**  
On September 30 of the current year, **Harborline Marine** sells equipment that had been depreciated through **December 31 of last year** only. Which sequence is correct?

- A) Remove cost and accum. dep. first, then record nine months of depreciation on the gain/loss residual  
- B) Record nine months of depreciation to update book value, then remove cost and accum. dep. and recognize gain or loss  
- C) Skip depreciation for the year of sale because the asset is gone at year-end  
- D) Capitalize the remaining book value into a new asset if proceeds will be reinvested  

**Answer:** **B.** Depreciation must be updated **through the disposal date** so the carrying amount is current; only then is the asset derecognized and gain/loss measured. Skipping depreciation understates expense and misstates gain/loss. Reinvestment does not defer recognition of gain/loss on disposal of the old asset.

---

**Question 2:**  
**Summit Castings** abandons a fully updated machine (no scrap proceeds) and, in a separate event, collects insurance after a storm destroys a different machine. Which statement is correct?

- A) Abandonment never produces a loss if the asset was fully depreciated only to residual; storm losses are deferred until insurance is settled for more than cost  
- B) Abandonment loss equals updated book value when proceeds are zero; involuntary conversion gain/loss equals insurance (or other) proceeds minus updated book value and is recognized even if proceeds will replace the asset  
- C) Both losses must be reported as discontinued operations  
- D) Accumulated depreciation is left on the books until the asset’s original useful life expires  

**Answer:** **B.** With zero proceeds, loss = updated BV. For involuntary conversion to cash/insurance, compare proceeds to updated BV; recognition is not deferred solely because replacement is planned. Ordinary PPE disposal G/L is **continuing operations**, and accum. dep. is **removed** with the asset at disposal.
