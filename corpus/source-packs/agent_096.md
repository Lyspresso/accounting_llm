# Agent 96 — CORE DEMO — LO 15-3

**Chapter:** 15  
**LO title:** Record accruals for payroll, compensated absences, bonuses, and defined contribution plans  
**Critical gap LO:** no

## Concept list for this pack
- **Initial recognition JE — employee payroll:** Salaries Expense for gross pay; credit statutory/voluntary withholdings and Salaries Payable (net)
- **Initial recognition JE — employer payroll taxes:** Payroll Tax Expense; FICA (employer match), FUTA, SUTA payables
- **Settlement/remittance JE:** pay net salaries to employees; remit withholdings and employer taxes to governments/third parties
- **Compensated absences (ASC 710):** accrue when rights vest or accumulate, services already rendered, payment probable, amount reasonably estimable
- **Subsequent measurement / usage:** reverse Accrued Compensation when vacation is taken; wage-rate change is a change in estimate (current Salaries Expense)
- **Bonus accrual:** expense and liability in the year services are performed (period-end adjusting JE)
- **Defined contribution plan:** Pension Expense = required employer contribution for the period; Accrued Pension Liability until remitted to trustee
- **Classification/presentation:** employee-related accruals as current liabilities; no accrual when payment is only *possible* (not probable)
- **Number-variant twin:** same lifecycle with fully changed facts and amounts

### Q1 — CORE — Payroll lifecycle + employee accruals (emphasis: initial recognition JE)
**LO:** LO 15-3  
**Concept:** Initial recognition of employee payroll withholdings and employer payroll taxes; period-end accruals for vacation, bonus, and defined contribution match; settlement remittance  
**Scenario:**  
**Harborline Analytics LLC** (calendar-year) summarizes **March** payroll and year-end employee obligations as follows.

**Part A — March weekly payroll (week ended March 28)**  
Gross wages for the week: **$64,000**

| Withholding / rate | Amount or rate |
|---|---|
| Federal income tax withheld | $15,200 |
| State income tax withheld | $3,840 |
| FICA (employee share) | 7.65% of gross |
| Employee voluntary 401(k) contributions | $1,280 |
| Employee health-care premiums | $1,920 |
| Employer FICA | 7.65% of gross |
| FUTA | 0.6% of full gross (all wages still within wage base for simplicity) |
| SUTA | 5.4% of full gross |

**Part B — March 31 period-end employee accruals (separate from weekly payroll)**  
1. Vested vacation rights attributable to services already rendered; payment probable; reasonably estimated at **$42,000**.  
2. Board approved a cash bonus of **$22,000** for services performed in the first quarter; payable April 15.  
3. Employer defined contribution match for March is **$5,600**, payable in April to the plan trustee.

**Part C — Settlement**  
On **April 2**, Harborline (1) pays employees their March 28 net salaries and (2) remits **all** March 28 payroll-related withholdings and employer payroll taxes to the appropriate parties (single combined remittance entry is acceptable). Bonus and pension accruals from Part B remain unpaid until later dates (do not pay them in Part C).

**Required:**  
a. Record the **March 28** entry for employee payroll and withholdings (**initial recognition**).  
b. Record the **March 28** entry for **employer payroll taxes** (**initial recognition**).  
c. Record the **March 31** adjusting entries for (1) compensated absences, (2) bonus, and (3) defined contribution plan.  
d. Record the **April 2** settlement entries: (1) payment of net salaries and (2) remittance of all March 28 withholdings and employer payroll taxes.  
e. Briefly state how the unpaid March 31 accruals from part (c) are **classified** on the March 31 balance sheet.

**Answer key:**  

**a. March 28 — employee payroll and withholdings (initial recognition)**

FICA payable (employee) = \(0.0765 \times \$64{,}000 = \$4{,}896\)

Salaries Payable (net)  
\(= \$64{,}000 - \$15{,}200 - \$3{,}840 - \$4{,}896 - \$1{,}280 - \$1{,}920 = \$36{,}864\)

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Expense | 64,000 | |
| Withholding Taxes Payable—Federal | | 15,200 |
| Withholding Taxes Payable—State | | 3,840 |
| FICA Taxes Payable | | 4,896 |
| Retirement Contributions Payable | | 1,280 |
| Health Care Premiums Payable | | 1,920 |
| Salaries Payable | | 36,864 |
| *Record gross payroll and statutory/voluntary withholdings* | | |

**Check:** Dr 64,000 = Cr 15,200 + 3,840 + 4,896 + 1,280 + 1,920 + 36,864. **Balanced.**

**b. March 28 — employer payroll taxes (initial recognition)**

| Component | Computation | Amount |
|---|---|---:|
| Employer FICA | \(0.0765 \times \$64{,}000\) | 4,896 |
| FUTA | \(0.006 \times \$64{,}000\) | 384 |
| SUTA | \(0.054 \times \$64{,}000\) | 3,456 |
| **Payroll Tax Expense** | sum | **8,736** |

| Account | Debit | Credit |
|---|---:|---:|
| Payroll Tax Expense | 8,736 | |
| FICA Taxes Payable | | 4,896 |
| FUTA Taxes Payable | | 384 |
| SUTA Taxes Payable | | 3,456 |
| *Employer payroll tax accrual* | | |

**Check:** Dr 8,736 = Cr 4,896 + 384 + 3,456. **Balanced.**

Combined FICA Taxes Payable after (a)+(b) = \(4{,}896 + 4{,}896 = \$9{,}792\).

**c. March 31 — period-end employee accruals**

*(1) Compensated absences*

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Expense | 42,000 | |
| Accrued Compensation | | 42,000 |
| *ASC 710: vest/accumulate, services rendered, probable, estimable* | | |

**Check:** 42,000 = 42,000.

*(2) Bonus accrual*

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Expense | 22,000 | |
| Salaries Payable (or Bonuses Payable) | | 22,000 |
| *Bonus for services already performed; unpaid at period-end* | | |

**Check:** 22,000 = 22,000.

*(3) Defined contribution plan*

| Account | Debit | Credit |
|---|---:|---:|
| Pension Expense | 5,600 | |
| Accrued Pension Liability | | 5,600 |
| *DC plan: expense equals required employer contribution for the period* | | |

**Check:** 5,600 = 5,600.

**d. April 2 — settlement / remittance**

*(1) Pay employees net pay*

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Payable | 36,864 | |
| Cash | | 36,864 |

**Check:** 36,864 = 36,864.

*(2) Remit withholdings and employer payroll taxes*

| Account | Debit | Credit |
|---|---:|---:|
| Withholding Taxes Payable—Federal | 15,200 | |
| Withholding Taxes Payable—State | 3,840 | |
| FICA Taxes Payable (\(4{,}896 + 4{,}896\)) | 9,792 | |
| FUTA Taxes Payable | 384 | |
| SUTA Taxes Payable | 3,456 | |
| Retirement Contributions Payable | 1,280 | |
| Health Care Premiums Payable | 1,920 | |
| Cash | | 35,872 |
| *Remit employee withholdings and employer taxes to third parties* | | |

**Check:** Dr 15,200 + 3,840 + 9,792 + 384 + 3,456 + 1,280 + 1,920 = 35,872 = Cr Cash. **Balanced.**

**Roll-forward cash check:** total cash for March 28 payroll cycle = net pay + remittance  
\(= \$36{,}864 + \$35{,}872 = \$72{,}736 = \) gross wages \(+\) employer payroll taxes \(= \$64{,}000 + \$8{,}736\).

**e. Classification (March 31)**  
Accrued Compensation **$42,000**, Bonuses/Salaries Payable **$22,000**, and Accrued Pension Liability **$5,600** are all **current liabilities** (expected to be settled within the operating cycle / one year). They appear with other accrued payroll and employee-related payables (e.g., “Compensation and taxes withheld” line item in practice).

**Key insight:** **Initial recognition** of payroll creates multiple **current liabilities** (withholdings, net pay, employer tax payables). Period-end accruals for vacation, bonuses, and DC plan contributions match expense to the **period of service**, not the cash payment date. Settlement simply extinguishes those liabilities with cash.

### Q2 — CORE number variant — Full twin pack
**LO:** LO 15-3  
**Concept:** Number-variant twin: payroll + employer taxes + remittance; vacation accrual and use schedule; sales-based bonus; DC match  
**Scenario:**  
**Copper Creek Outfitters Inc.** (calendar-year) has the following facts.

**Payroll — week ended June 14**  
Gross wages: **$100,000**

| Item | Amount / rate |
|---|---|
| Federal income tax withheld | $24,000 |
| State income tax withheld | $5,000 |
| FICA employee | 7.65% of gross |
| Employee retirement contributions | $2,500 |
| Employee HSA contributions | $3,000 |
| Employer FICA | 7.65% of gross |
| FUTA | 0.6% of full gross |
| SUTA | 5.4% of full gross |

**Year-end / subsequent**  
- December 31, Year 1: unused vested vacation valued at **$68,000** (meets all ASC 710 criteria).  
- During Year 2: vacation used with original accrued cost of **$61,000**; **$7,000** of the Year-1 accrual remains unused at December 31, Year 2. Year-2 wage rates for employees who took the carryover vacation were **$2,500 higher** than the Year-1 accrual for that time (change in estimate). For simplicity, credit Cash for amounts paid.  
- June sales: **$725,000**. Executives earn a bonus equal to **3% of monthly sales over $600,000**, payable the following month.  
- June employer DC match (defined contribution): **$8,400**, payable next month to the trustee.

**Required:**  
a. Record June 14 payroll (employee) and employer payroll tax entries.  
b. Compute net Salaries Payable and total Payroll Tax Expense; show Dr = Cr.  
c. Prepare a **compensated absences roll-forward schedule** (beg. Year 2 through end Year 2) and the Year-2 journal entry when vacation is paid (with the wage-rate increase).  
d. Record June 30 bonus and defined contribution accruals.  
e. On July 5, Copper Creek remits **only** the June 14 FICA, FUTA, and SUTA payables (employer + employee FICA combined). Record that remittance.

**Answer key:**  

**a–b. June 14 payroll entries**

FICA (each side) = \(0.0765 \times \$100{,}000 = \$7{,}650\)

Salaries Payable  
\(= \$100{,}000 - \$24{,}000 - \$5{,}000 - \$7{,}650 - \$2{,}500 - \$3{,}000 = \$57{,}850\)

*June 14 — employee payroll*

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Expense | 100,000 | |
| Withholding Taxes Payable—Federal | | 24,000 |
| Withholding Taxes Payable—State | | 5,000 |
| FICA Taxes Payable | | 7,650 |
| Retirement Contributions Payable | | 2,500 |
| HSA Payable | | 3,000 |
| Salaries Payable | | 57,850 |

**Check:** 100,000 = 24,000 + 5,000 + 7,650 + 2,500 + 3,000 + 57,850. **Balanced.**

Employer taxes: FICA **7,650** + FUTA \(0.006 \times 100{,}000 = \$600\) + SUTA \(0.054 \times 100{,}000 = \$5{,}400\) → Payroll Tax Expense **$13,650**

*June 14 — employer payroll taxes*

| Account | Debit | Credit |
|---|---:|---:|
| Payroll Tax Expense | 13,650 | |
| FICA Taxes Payable | | 7,650 |
| FUTA Taxes Payable | | 600 |
| SUTA Taxes Payable | | 5,400 |

**Check:** 13,650 = 7,650 + 600 + 5,400. **Balanced.**

**c. Compensated absences — subsequent measurement schedule and settlement JE**

| Description | Amount |
|---|---:|
| Beginning Accrued Compensation (1/1/Y2) | 68,000 |
| Vacation used (at prior accrual rates) | (61,000) |
| Ending Accrued Compensation (12/31/Y2) before any new Y2 accrual | **7,000** |

*Year 2 — vacation time used (wage rates increased by $2,500)*  

Cash paid = prior accrual for time used + rate increase  
\(= \$61{,}000 + \$2{,}500 = \$63{,}500\)

| Account | Debit | Credit |
|---|---:|---:|
| Accrued Compensation | 61,000 | |
| Salaries Expense | 2,500 | |
| Cash | | 63,500 |
| *Settle liability at original accrual; rate change → current expense (change in estimate)* | | |

**Check:** Dr 61,000 + 2,500 = Cr 63,500. **Balanced.**

Remaining liability for unused carryover: **$7,000** (still Accrued Compensation).

**d. June 30 — bonus and DC plan**

Bonus base = sales above threshold = \(\$725{,}000 - \$600{,}000 = \$125{,}000\)  
Bonus = \(0.03 \times \$125{,}000 = \$3{,}750\)

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Expense | 3,750 | |
| Salaries Payable | | 3,750 |

| Account | Debit | Credit |
|---|---:|---:|
| Pension Expense | 8,400 | |
| Accrued Pension Liability | | 8,400 |

**Check:** each entry balances.

**e. July 5 — remittance of FICA / FUTA / SUTA only**

Combined FICA payable = \(7{,}650 + 7{,}650 = \$15{,}300\)  
Total remitted = \(15{,}300 + 600 + 5{,}400 = \$21{,}300\)

| Account | Debit | Credit |
|---|---:|---:|
| FICA Taxes Payable | 15,300 | |
| FUTA Taxes Payable | 600 | |
| SUTA Taxes Payable | 5,400 | |
| Cash | | 21,300 |

**Check:** 15,300 + 600 + 5,400 = 21,300. **Balanced.**

**Key insight:** Same structure as Q1 with all numbers changed. Vacation **settlement** debits the liability only for the amount previously accrued; a higher current wage is **Salaries Expense** (change in estimate), not a restatement of prior periods.

### Q3 — CORE alternate angle — Period-end adjusting + classification (sick vs vacation) + settlements
**LO:** LO 15-3  
**Concept:** Period-end adjusting JEs only; classification of compensated absences when payment is probable vs only possible; settlement of bonus and DC plan; presentation  
**Scenario:**  
**Northwind Paper Co.** is preparing **December 31, Year 1** adjusting entries and related Year-2 settlements. No weekly payroll entries are required in this problem (those were already recorded during the year).

| Item | Facts |
|---|---|
| Vacation pay | Rights **vest**; attributable to services already rendered; payment **probable**; reasonably estimated **$185,000** at Dec 31 Y1. Zero beginning balance. |
| Sick pay | Rights **do not vest** but **accumulate**; attributable to services already rendered; reasonably estimated **$72,000**; payment is only **possible** (not probable). |
| Executive bonus | Board approved **$95,000** on Dec 20 Y1 for Y1 services; payable **January 28, Year 2**. |
| Defined contribution plan | Employer match for Y1 = **$41,000**; paid to trustee on **January 10, Year 2**. |
| Vacation used in Y2 | Employees take vacation with carrying amount **$120,000** at original rates; no wage-rate change. Credit Cash. |

**Required:**  
a. Prepare **all December 31, Year 1 adjusting entries** that are required under GAAP. Explicitly state any item for which **no accrual** is made and why.  
b. What **total liability for compensated absences** is reported on the December 31, Year 1 balance sheet?  
c. Prepare the **January 10, Y2** and **January 28, Y2** settlement entries for the pension contribution and the bonus.  
d. Prepare the Year-2 entry when **$120,000** of accrued vacation is paid.  
e. **Presentation:** Identify the balance-sheet classification of each liability accrued in (a) at December 31, Year 1.

**Answer key:**  

**a. December 31, Year 1 adjusting entries**

*(1) Vacation — accrue (all four ASC 710 criteria met)*

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Expense | 185,000 | |
| Accrued Compensation | | 185,000 |

**Check:** 185,000 = 185,000.

*(2) Sick pay — **no accrual***  
Payment is only **possible**, not **probable**. Criterion (c) of ASC 710-10-25-1 fails → **no liability and no expense** for the $72,000 accumulated sick pay. (If the first three criteria were met but the amount could not be estimated, disclosure-only would apply; here the barrier is probability.)

*(3) Bonus*

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Expense | 95,000 | |
| Salaries Payable | | 95,000 |

**Check:** 95,000 = 95,000.

*(4) Defined contribution plan*

| Account | Debit | Credit |
|---|---:|---:|
| Pension Expense | 41,000 | |
| Accrued Pension Liability | | 41,000 |

**Check:** 41,000 = 41,000.

**b. Compensated absences liability, Dec 31 Y1**  
Report **$185,000** (vacation only). Sick pay **$0** accrued.

**c. Settlements**

*January 10, Year 2 — pay DC contribution to trustee*

| Account | Debit | Credit |
|---|---:|---:|
| Accrued Pension Liability | 41,000 | |
| Cash | | 41,000 |

**Check:** 41,000 = 41,000.

*January 28, Year 2 — pay bonus*

| Account | Debit | Credit |
|---|---:|---:|
| Salaries Payable | 95,000 | |
| Cash | | 95,000 |

**Check:** 95,000 = 95,000.

**d. Year 2 — vacation used / paid**

| Account | Debit | Credit |
|---|---:|---:|
| Accrued Compensation | 120,000 | |
| Cash | | 120,000 |

**Check:** 120,000 = 120,000.

Remaining Accrued Compensation = \(185{,}000 - 120{,}000 = \$65{,}000\).

**e. Classification / presentation (Dec 31 Y1)**  
| Liability | Amount | Classification |
|---|---:|---|
| Accrued Compensation (vacation) | 185,000 | **Current liability** |
| Salaries Payable (bonus) | 95,000 | **Current liability** |
| Accrued Pension Liability (DC) | 41,000 | **Current liability** |
| Sick pay | — | Not recognized (possible only) |

All three recognized items are operating current liabilities arising from employee services.

**Key insight:** Compensated absences require **all four** ASC 710 criteria—**probable** payment is often the decisive test for nonvested sick leave. Period-end adjusting entries recognize expense in the **service period**; subsequent cash payments are pure **settlements** of the liability.

### Q4 — MC — Compensated absences recognition criteria
**LO:** LO 15-3  
**Concept:** When to accrue a liability for compensated absences (ASC 710 four criteria)  
**Question:**  
At year-end, an employer evaluates unused employee time off. Which situation requires **recognition of a liability** for compensated absences?

- A) Sick pay that accumulates but does not vest; payment is only **possible**; amount can be estimated.  
- B) Vacation pay that **vests**, relates to services already rendered, payment is **probable**, and the amount can be **reasonably estimated**.  
- C) Future holiday pay for next year’s holidays that employees have **not yet earned** through services rendered.  
- D) A nonvested benefit that accumulates, payment is probable, but the company **cannot reasonably estimate** the amount (and the first three criteria are otherwise met).

**Answer:** **B.**  
ASC 710-10-25-1 requires accrual when (1) the obligation is attributable to services already rendered, (2) rights vest or accumulate, (3) payment is probable, and (4) the amount can be reasonably estimated. **B** meets all four. **A** fails probability. **C** fails “services already rendered.” **D** requires **disclosure only**, not recognition, when the amount cannot be estimated.

### Q5 — MC — Defined contribution vs other employee accruals
**LO:** LO 15-3  
**Concept:** Measurement of defined contribution pension expense vs bonus/payroll liabilities  
**Question:**  
Under a **defined contribution** retirement plan, the employer’s pension expense for the period equals:

- A) The present value of estimated future retirement benefits promised to employees.  
- B) The actuarially determined service cost plus interest cost minus expected return on plan assets.  
- C) The **required employer contribution** for the period (paid or payable), with no further liability once that contribution is made (assuming contributions are not deferred past the service period).  
- D) Employee FICA withholdings remitted to the U.S. Treasury.

**Answer:** **C.**  
For defined contribution plans, the employer’s obligation is limited to the formula contribution for the period (ASC 715-70). That amount is Pension Expense, with Accrued Pension Liability if unpaid. **A** and **B** describe **defined benefit** plans (Chapter 23). **D** is a payroll withholding, not pension expense.
