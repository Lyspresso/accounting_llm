# Glossary — read this first; the vocabulary is load-bearing
- **Lineage**: one question's identity across repairs (1,828 total).
  **Hash**: one content version. **Row**: one ledger event. The unit
  ladder: rows < hashes < lineages; funnels speak lineages.
- **Terminal**: `verified` | `needs_human` ONLY. `machine_passed` /
  `failed` are Stage-1 progress states.
- **Class A / Class B**: machine-verifiable (1,232) / judgment MCQs (596).
- **Harnesses**: `baseline-1` (terse reporter), `trim-1` (adopted
  production harness; instructs required-figure coverage), `dual-1`
  (second blind derivation). All built by ONE builder; role varies one
  framing line.
- **KEY_SILENT**: a required figure the key doesn't state; verified only
  by dual derivation (`verified_by_derivation`) or stays unverified.
- **Coverage debt**: required figures not yet verified — gates VERIFIED
  labels; NOT a comparator false positive.
- **Floors**: probe detection ≥85% (statistical) and TRUE_FP ≤10%.
  Floor-#2 failure classes: TRUE_FP / PENDING / MATCHER_ARTIFACT /
  HASH_MIXING / GOLDEN_WRONG. Only TRUE_FP counts.
- **Canary**: planted wrong key value; agreement = blindness breach.
- **canon**: the ONE arithmetic-equivalence library (precision
  inheritance, context-scoped rounding, net-per-account, declared scale,
  prose-null, percent↔fraction). **ledger_io**: the ONE ledger write
  path. **banned_patterns()**: the ONE ruling-pattern generator.
- **PACK_NOTES_STALE**: cached output whose generation-time pack context
  no longer matches current; retained as record, excluded from verdicts.
- **Fix classes (zero remake budget)**: KEY_REPAIR (source pack), stem
  clarification (⇒ re-solve), pack treatment note (builder-wired,
  wiring-probed, patch-before-run).
- **Gates**: LAUNCH (RED/GREEN, pre-flight decides) vs FAMILY gates
  (e.g., LO 11-8 — LIFTED). Distinct things.
- **Maxxer / Budget**: run-size modes; identical law, identical frontier
  models. deliver.sh: the only way exports ship (regenerates + stamps).
